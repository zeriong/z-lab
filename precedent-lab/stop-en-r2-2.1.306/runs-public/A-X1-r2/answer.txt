**What this costs:** the tab key is both the React key and the URL state. Closing a tab now changes the key of every tab to its right, so React remounts them and they lose their scroll position and unsaved form input. That is the behaviour behind the 2026-08-29 incident, and the test that reproduced it is gone. Saved `?tabs=` URLs can also point to different tabs after a close. I wrote this into the record as a "Known cost" line. If you need contiguous URLs but want tabs to survive a close, the usual fix is to give each tab a separate stable id for the React key and keep the contiguous key only for the URL.
