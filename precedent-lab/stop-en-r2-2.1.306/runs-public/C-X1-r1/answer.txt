**Decision for you**
- **Remounts are back:** the tab key is still both the React key and the URL state. Closing a tab changes the key of every tab to its right, so React remounts those tabs and they lose scroll position and unsaved form input. That is the 2026-08-29 incident behaviour. I listed it in the record as "Known cost". If you want contiguous URLs without the remounts, the React key needs to come from a stable ID that is separate from the key used in the URL.
