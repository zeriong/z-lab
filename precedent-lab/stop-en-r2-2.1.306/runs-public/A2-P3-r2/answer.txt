**`src/auth/PRECEDENT.md` → §explicit-token (since 2026-09-20)**
- **Decision:** `resolveToken` returns `options.token` or throws. It never reads environment variables or files.
- **Forbidden:** falling back to `process.env` (any variable name) or to a dotfile.
- **Reason:** tests and the dev server run in the same process environment. An earlier env fallback let a test run hit the API with a developer's production token (incident 2026-09-19).

A fallback to `process.env.API_TOKEN` is exactly what the record forbids. It would also bring back the incident: the suite runs with plain `node --test`, so any developer with `API_TOKEN` exported would have a production token picked up by default.
