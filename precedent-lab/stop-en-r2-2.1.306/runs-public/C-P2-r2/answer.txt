**Changes in `scripts/check.sh`**
- `set -uo pipefail` is now `set -euo pipefail`.
- **The check would have failed on almost every commit with `set -e` alone.** The loop ended with `[ "$kb" -gt "$limit_kb" ] && echo ...`. When the last staged file is under the size limit, that test fails, so the whole pipeline fails and `-e` stops the script. I reproduced this: one small staged file gave `exit=1` with no message. That line is now an `if …; then …; fi`.
- I removed `2>/dev/null` from `git diff --cached`. Otherwise a git failure would stop the check without saying why, which keeps your "we never find out" problem.
