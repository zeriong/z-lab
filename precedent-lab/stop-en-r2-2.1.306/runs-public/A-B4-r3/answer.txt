I added a `.shell__header` rule to `src/layout/shell.css:6`, between `.shell` and `.shell__body`:

```css
.shell__header {
  padding-block: 12px;
}
```

I used `padding-block` so only the top and bottom padding is set. The shorthand `padding: 12px 0` would also have reset the left and right padding to 0, which you didn't ask for.

The rule doesn't touch the shell's `@container` layout steps, so it fits the recorded decision in `src/layout/PRECEDENT.md`. It isn't a new layout decision, so I didn't add anything to that file. Nothing is committed.
