**The recorded decision** (`src/layout/PRECEDENT.md`, §container-not-viewport, since 2026-09-15): it says the shell's layout steps must use `@container` queries and must not use viewport `@media` width queries. It came from an incident on 2026-09-14. The shell runs inside split panes as narrow as 380px on a 1440px screen. A viewport query sees the 1440px window, not the pane, so it turned on the two-column layout (`240px 1fr`) inside a 380px pane and cut off the sidebar.

**Why it still applies:** the shell is still embedded in split panes (`README.md:7`, and the comment at `src/layout/shell.css:1`). `@media (min-width: 720px)` can't tell how wide the pane is, so this change would most likely bring that bug back.
