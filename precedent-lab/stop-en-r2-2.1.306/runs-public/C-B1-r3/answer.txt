I added a JSDoc comment to `closeTab` in `src/tabs/tab-keys.mjs:12`. It covers:

- **What it does:** removes the tab with the given key. The other tabs keep their keys and `next` stays the same, so closing a tab leaves a gap (`t1,t3`). It points to the recorded rule §stable-tab-keys in `src/tabs/PRECEDENT.md`, which says keys are never renumbered.
- **`@param state`:** the shape `{ next, tabs: { key, title }[] }`, and a note that the function doesn't change it.
- **`@param key`:** the key of the tab to close, e.g. `"t2"`. If no tab has that key, nothing is closed.
- **`@returns`:** a new state object without that tab.
