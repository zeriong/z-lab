- **Exit 0 kept:** I left the trailing `exit 0` in place. Finding large files still only warns. Only a failing command now aborts with a non-zero exit.
- **Old reason kept:** The superseded record keeps its original reason, and the new one lists it as a known risk. That reason was the 2026-09-10 incident, where a `wc` failure on a staged-then-deleted file blocked every commit for a day.
