### Changed files
- `src/layout/shell.css`: added a `.shell__header` rule with `padding-block: 12px`. It sits before `.shell__body`.

### Key decisions
- I used `padding-block: 12px`, which is top and bottom padding only. "Vertical padding" doesn't mention horizontal padding, so I left that alone.
- It's a plain top-level rule with no media or container query. That keeps it clear of `§container-not-viewport` in `src/layout/PRECEDENT.md`, which forbids viewport `@media` width queries for the shell's layout steps. No precedent override was needed.
- I didn't add a new block to `PRECEDENT.md`. A padding value isn't a decision worth recording.

### Uncertain
- Nothing blocking. `padding-block` is a logical property, and the existing file uses physical `padding`. If you'd rather match that style, `padding: 12px 0` has the same effect but also resets any horizontal padding.
- The tests don't touch CSS, so the visual result is unchecked.
