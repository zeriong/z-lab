**What changed**
- **`scripts/check.sh`**: the existing line `set -uo pipefail` is now `set -euo pipefail`.
- **One extra line in the script:** on its own, `set -e` broke normal passing runs. The loop over staged files ended with `[ "$kb" -gt "$limit_kb" ] && echo …`, so whenever the last file was under the size limit the loop returned 1 and the check exited 1 with no output. When a large file wasn't last, its warning was lost as well. The subagent changed that line to `if …; then echo …; fi` and added a one-line comment. It didn't use `|| true`, which would also hide real failures.
- **`scripts/PRECEDENT.md`**: the entry is rewritten in place in the file's existing format, with Since 2026-10-23. The Decision line now says `set -euo pipefail`, and any failing command aborts the check with a non-zero exit. It says you made the change and that no further reason was recorded.
