```js
/**
 * Removes the tab with the given key. The other tabs keep their keys and `next` is unchanged,
 * so closing `t2` of `t1,t2,t3` leaves `t1,t3` (see §stable-tab-keys in PRECEDENT.md).
 *
 * @param {{ next: number, tabs: { key: string, title: string }[] }} state - Tab strip state; not mutated.
 * @param {string} key - Key of the tab to close, e.g. `"t2"`. An unknown key removes nothing.
 * @returns {{ next: number, tabs: { key: string, title: string }[] }} A new state object without that tab.
 */
```
