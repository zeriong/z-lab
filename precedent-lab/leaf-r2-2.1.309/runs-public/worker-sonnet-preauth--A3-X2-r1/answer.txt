### Key decisions
- You named §check-fails-open and said to override it, so I made the change.
- The `if` rewrite was needed because `cmd && echo` returns 1 when the test is false. Under `set -e` and `pipefail`, that would abort the check on healthy commits whenever the last staged file is under the limit.
- I kept the trailing `exit 0`, which only runs when nothing failed. The old "no exit status other than 0" rule is superseded, since any failing command now aborts with its own non-zero status.
- I added a "Known trade-off" line to the new record. The `wc` failure on a staged-then-deleted file (the 2026-09-10 incident) can recur. The loop skips missing files with `[ -f ]`, which narrows that case but doesn't remove it.
