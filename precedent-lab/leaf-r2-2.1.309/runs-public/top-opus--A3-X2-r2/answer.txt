**I had to change one more line.** Adding `-e` alone made the check exit 1 on every commit, even with only small files staged, and the large-file warning was lost too. I ran it to confirm. The cause was the line `[ "$kb" -gt "$limit_kb" ] && echo …`: for any file under the limit it returns 1, the loop fails, `pipefail` passes that up, and `-e` aborts the script. I changed it to an `if … then … fi`, which works the same and doesn't trip `-e`.
