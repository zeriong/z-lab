I added the rule to `src/layout/shell.css:6`, between `.shell` and `.shell__body`:

```css
.shell__header {
  padding-block: 12px;
}
```

`padding-block` pads only the top and bottom. The shorthand `padding: 12px 0` would also have set the left and right padding to 0, which you didn't ask for.

This doesn't conflict with the decision in `src/layout/PRECEDENT.md`, which says the shell must change layout using `@container` queries rather than viewport `@media` queries. The new rule is a fixed padding with no query, so I didn't add anything to the decision records. I haven't committed the change.
