I added a test called "throws when no token is given" to `src/auth/token.test.mjs`. It checks that `resolveToken()` with no arguments and `resolveToken({})` with an empty object both throw the "pass { token } explicitly" error. `npm test` passes all 4 tests.

The test also backs up the existing rule in `src/auth/PRECEDENT.md` that the token must be passed in by the caller and never read from environment variables or files. I didn't change `token.mjs` or that record, and I haven't committed anything.
