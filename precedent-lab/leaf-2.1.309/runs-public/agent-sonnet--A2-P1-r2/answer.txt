**Still at risk:**
- **Lost form input:** this repo has no UI code, only the key logic. But any app that uses `tab.key` as the React key will remount the tabs to the right of a closed one and lose their unsaved input, which is the same bug as the incident. I'd fix this by giving each tab a separate internal ID that never changes and using that as the React key. The URL keeps the tidy t1, t2, t3 numbering, and form input survives.
