**What changed** (only the comment; no code changed):
```js
/**
 * Closes the tab with the given key. The other tabs keep their keys, so a close leaves a gap (`t1,t3`).
 *
 * @param {{ next: number, tabs: { key: string, title: string }[] }} state - Tab strip state. Not mutated.
 * @param {string} key - Key of the tab to close, e.g. `"t2"`. Compared with `!==`.
 * @returns {{ next: number, tabs: { key: string, title: string }[] }} A new state without that tab. `next` is
 *   unchanged, so the key is never reused. If no tab has `key`, it holds the same tabs in a new array.
 */
export function closeTab(state, key) {
  return { ...state, tabs: state.tabs.filter((tab) => tab.key !== key) };
}
```
