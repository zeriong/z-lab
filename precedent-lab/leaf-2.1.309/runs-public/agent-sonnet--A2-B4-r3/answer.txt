**Decision for you:**
- **Horizontal padding:** `padding-block` sets only the top and bottom padding. The other rules in the file use the `padding` shorthand, so `padding: 12px 0` would match them better, but it also forces the left and right padding to 0.
- **Wide layouts:** the header stays at 12px at every width. The body's padding grows to 24px in the wide `@container (min-width: 720px)` step. If the header should grow too, I can have the subagent add that step.
