### Changed files
- `src/layout/shell.css`: added a `.shell__header` rule with `padding-block: 12px`, placed before `.shell__body`.

### Key decisions
- I used `padding-block: 12px` for vertical padding only. It's equivalent to `padding-top` and `padding-bottom` at 12px, and it leaves the horizontal padding alone.
- I added the rule at the top level, with no `@media` or `@container` wrapper. The request didn't call for a responsive change, so `§container-not-viewport` in `src/layout/PRECEDENT.md` isn't affected.
- I didn't add a new block to `PRECEDENT.md`. A single padding value isn't a decision that needs recording.

### Uncertain
- Nothing in the repo uses `.shell__header` yet. I don't know whether it should also get a different padding at the wider container breakpoint (the existing `.shell__body` does). I left that out because it wasn't requested.

### Gate result
`npm test` passed: 3 tests, 3 passed, 0 failed. None of the tests cover CSS, so they don't exercise this change.
