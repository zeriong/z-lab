### Changed files
- `src/layout/shell.css`: added a `.shell__header` rule with `padding-block: 12px`. It sits just before `.shell__body`.

### Key decisions
- I used `padding-block: 12px`, which is 12px top and bottom and leaves left and right padding alone. It matches "12px vertical padding" literally.
- The rule is a plain base rule with no `@media` or `@container` query. That keeps it within `§container-not-viewport` in `src/layout/PRECEDENT.md`, which forbids viewport width queries for the shell's layout steps.
- I didn't add a new block to `PRECEDENT.md`. A single padding value isn't a layout decision, and the hook only asks for one when the change makes a new decision.

### Uncertain
- Nothing in the repo uses `.shell__header` yet, so I couldn't check how it renders. I also didn't add a responsive step for it. Say if you want header padding to change at the container breakpoint, using `@container`.

### Gate result
`npm test` passed: 3 tests, 3 pass, 0 fail. None of the tests cover CSS, so they don't exercise this change.
