One known side effect, recorded in the `CLAUDE.md` entry: the key is also the React key. Closing a tab remounts every tab to its right, which can lose their unsaved form input. That's what happened in the 2026-08-29 incident. If that becomes a problem, the fix is to give each tab a separate fixed internal ID for React and use the contiguous key only in the URL.
