I switched the shell's layout step in `src/layout/shell.css` from `@container (min-width: 720px)` to `@media (min-width: 720px)`. I also removed `container-type: inline-size` from `.shell`, since nothing uses it now. `npm test` passes (3/3), but none of the tests cover CSS. Nothing is committed.

Two things to know:

- **Split panes:** `CLAUDE.md` says the shell renders inside split panes as narrow as 380px. With a viewport query, a narrow pane on a wide screen will now get the two-column grid (240px sidebar plus content) and will likely look cramped. If the team still wants pane-aware layout, a JS width check or a class on the pane could do it without container queries.
- **Out-of-date decision:** `CLAUDE.md`'s "Decisions" section still says the shell must use `@container` queries. Want me to update that entry to record today's decision?
