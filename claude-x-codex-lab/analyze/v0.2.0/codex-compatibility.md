## Decision

Preserve the Claude workflow, names and artifacts. Add host adapters, native manifests and explicit host selection. Codex reviewers inherit the current model and effort; the Claude panels keep their original model choices. This is a maintenance decision, not a measured model ranking. Share workflow/agent definitions and deterministic gates. Test actual runtime hooks separately from their declarations.

## Follow-up limits

Run broader real projects and actual browser/device measurements before asserting universal portability or quality gains. Respect protected configuration paths and report pending activation honestly. The compatibility smoke tests do not eliminate these environment requirements.
