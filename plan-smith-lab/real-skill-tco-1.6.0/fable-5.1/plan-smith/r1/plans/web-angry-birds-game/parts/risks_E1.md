## 10. 대안과 기각 사유 (각각 부활 트리거)

- TypeScript/번들러/npm — 구현자가 설치·빌드 불가. **구현자에게 설치·빌드·실행 환경이 주어지면 재개.**
- ES 모듈(`import/export`) · 외부 JSON `fetch()` — `file://` 에서 Chromium 이 CORS 로 차단. **산출물이 HTTP 로만 서빙된다는 보장이 생기면 재개.**
- 물리 엔진 직접 구현 — 회전 강체 적층·붕괴를 무테스트로 맞게 쓰기 어려움. **CDN 로드가 불가한 오프라인 요구가 생기고 벤더링 수단도 없으면 재개.**
- Phaser 등 프레임워크 — API 표면이 커서 기억 의존 오류 확률↑. **구현자가 실행·테스트할 수 있게 되면 재개.**
- Matter `Render`/`Runner` — 고무줄·궤적·HUD 를 못 그리고 Runner 는 버전별 거동이 다름. **디버그 뷰가 필요하면 보조 캔버스로만 재개.**
- `Constraint` 고무줄 발사 — 제약 해제 타이밍(새가 앵커를 지나야 풀림) 버그를 무테스트로 못 잡음. **검수에서 수동 발사의 손맛이 부족하다는 피드백이 오면 재개.**
- `Body.setStatic(bird,false)` 토글 — 정적 생성 시 질량 복원 여부가 버전에 걸려 있음. **검수에서 "월드 밖 새" 방식이 렌더/충돌에 문제를 보이면 재개.**
- 캔버스 안 버튼 — 히트테스트 좌표 버그 온상. **풀스크린 캔버스 전용 렌더링이 요구되면 재개.**
- 이미지·오디오 에셋 — 바이너리 생성 불가. **에셋 팩이 공급되면 재개.**

## 11. 리스크와 완화

- CDN 미가용 → 행 T 의 가시 에러 + §3 폴백(로컬 복사 한 줄).
- Matter API 이름 오기억 → §5.4 표의 이름만 사용, `World.*`/`Runner` 금지 목록.
- 최상위 `const` 중복 선언으로 파일 통째 실패 → 별칭·상수는 `physics.js` 에만, `G` 는 `game.js` 에만, 함수명은 §5.4 에서 유일.
- 충돌 콜백 안에서 몸체 제거 → 큐 후처리(`flushRemovals`)로 분리.
- 초기 겹침으로 구조물이 튐 → §6 좌표는 맞닿음만 허용하도록 계산됨; 새 스테이지를 추가할 때도 같은 규칙.
- 오버레이가 포인터를 가림 → `.hidden` 이 `display:none`; HUD 는 `pointer-events:none`.
- 캔버스 CSS 축소 시 좌표 어긋남 → `toCanvasPoint` 의 비율 보정.
- 120Hz 에서 2배속 → 고정 스텝 누산기(§7.3).
- 오디오 자동재생 차단 → `AudioContext` 를 첫 사용자 입력에서 생성.
- `localStorage` 예외(private 모드) → try/catch, 실패 시 메모리 값으로 진행.
- 새가 구조물 위에 얹혀 영원히 안 멈춤 → `MAX_FLIGHT_TICKS` 8초 상한.
