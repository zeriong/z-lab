# 메모 저장 형식 결정

## 완료 기준부터 역산
- 가: 오프라인 저장·재시작으로 제목·본문이 보존된다. 외부서비스·휘발저장을 배제한다.
- 나: 저장중 종료해도 기존본이나 새본이 완전하다. 직접 덮어쓰기를 배제한다.
- 다: 사람이 저장·백업·복구를 설명·재현한다. 불투명한 복잡성을 배제한다.

실패하면 저장설계를 재작성하므로 앵커다. 건수·속도 임계값은 불필요하다.

## 문제와 판단
추론틀: backward / 스타일: opus. SQLite부터 고르는 습관을 접고 역산한다. **JSON을 우선 선택한다.** 단독사용에서 확인·복구가 쉽다.

## 가정과 교차검토
**임시파일 저장·교체가 중단검증을 통과한다**고 가정한다. 틀리면 SQLite로 전환한다. 가×나는 완전성, 가×다는 읽기·복구, 나×다는 복구본 보존을 요구한다. 나의 검증부터 한다.

## 의존관계와 검증
- 독립: 사람이 실행환경을 확인한다. 임시파일 기록·교체 전후 강제종료하고 읽어 나를 검증한다. 실패하면 SQLite도 검증한다.
- 중단검증 필요: UTF-8 JSON에 제목·본문을 저장한다. 재시작·원문대조로 가를 검증한다.
- 저장검증 필요: 파일복사 백업·복원·원문대조로 다를 검증한다.

핵심 경로: 중단검증→저장→복원. 앵커 밖 요구는 구조를 바꾸지 않아도 출하한다. 단독사용·무동기화·무동시성은 위 절차에 반영한다.

## 대안·위험·미확정
SQLite는 관리부담으로 보류한다. 중단검증 실패·부분갱신·검색·전체저장 불편이 재검토 조건이다. 건수·첨부·검색·백업주기·실행환경은 미정이다. 측정하기 어려운 편의성은 복구절차 설명으로 확인한다. 호스팅은 거절됐으며 오프라인 요구변경·재승인이 재검토 조건이다.

## 완료와 구현자 계약
사람이 원문·중단·복원 검증을 통과하면 완료다. UTF-8 JSON, 언어는 미정이다. `python3 -m json.tool notes.json`은 구문검사다. 내용·중단안전성은 위 절차로 증명한다. 구현·커밋은 금지한다.

## Frame deviations & habit regressions
‘문제와 판단’의 관리부담은 정성판단이다. 가장 약한 ‘가정’의 교체보장을 검토해야 한다. ‘계약’의 구문검사는 관례이며 안전성 증명이 아니다.
