# 번아웃 복귀 8주 계획 — 바닥부터 쓴다

- 추론 프레임: safety-net
- 한 줄 요약: 8주 내내 동일한 단일 복귀 상태(바닥)를 먼저 고정하고, 상향은 프로브가 통과할 때만 한 칸씩, 하향은 본인 판단이 아니라 대리인과 기존 기록이 즉시 집행한다.

## 프레임이 요구하는 시작점 — 단일 바닥 상태 F

바닥은 주마다 달라지지 않는다. 8주 동안 하나다. 주별 "플랜 B"는 새 바닥이 아니라 **F로의 하향 지시**다.

**F(복귀 최소 상태)** ① 연속 4시간 근무, 재택 우선 ② 회의 0건, 예외는 주 1회 15분 1:1 하나 ③ 0주차에 매니저와 문서로 지명한 저위험 단일 트랙 1종만 ④ 신규 요청 수락 권한 0 — 모든 유입은 매니저로 라우팅(자동응답 + 게이트키핑) ⑤ 온콜·야간·주말 연락 제외, 말이 아니라 계정 권한·알림 채널에서 제거 ⑥ 수면 시간과 진료·투약 일정 유지는 F의 구성요소다.

4시간·1종·15분은 **선언적 자의값**이다. 수명 상한: 1주차 종료 시 근태 로그의 실제 종료 시각으로 대체하고, 판독자는 대리인, 도구는 이미 쓰는 근태 시스템이다.

**전체 창 거주성 검사(0주차 착수 조건).** 8주 전부 F에 머물러도 고용·생계가 끊기지 않아야 바닥이 옳다. 인사팀·약관에 서면으로 5개를 묻는다 — 단축근무 승인 상한 / 급여 삭감률 / 평가·수습 제외 조건 / 병가 잔여일 / 소득보전 특약. 답이 "8주 F 불가"면 바닥이 틀린 것이고 즉시 대안 A로 전환한다. 빈칸을 추정치로 채우지 않는다.

**진행성 악화 예외 경로.** 동결로 수렴하지 않는 손상은 F가 막지 못한다. 수면 붕괴 3일 연속, 공황 빈도 증가, 자해·자살 사고 중 하나가 관측되면 F 아래의 별도 경로 — 24시간 내 임상 접점 예약 + 병가 즉시 사용(신청은 대리인 대행). 동시에 F보다 공격적인 자동조치를 금지한다: "부진하니 다음 주에 늘려 만회", 자동 사직, 프로젝트 자발 반납은 어떤 트리거로도 발화하지 않는다.

## 문제 정의 / 목표

목표는 8주 후 원래 업무량 복귀가 아니다. 8주 동안 F가 무너지지 않는 것, 그리고 하향이 필요한 순간마다 집행된 기록이 남는 것이다.

## 명시적 가정

1. **대리인 1명(매니저 아닌 사람 우선)을 지정하고, 본인 동의 없이 하향을 집행할 서면 위임을 0주차에 받는다.** 번아웃이 파괴한 기능이 판단력이므로 "힘들면 줄인다"는 트리거가 될 수 없고, 전체가 여기 걸린다. 틀렸을 경우: 하향이 발화하지 않고 문서는 낙관 경로로 되돌아간다. 최저 비용 검증 = 위임문 1장 서명(15분). 대체 경로 = 사람 대신 기본값을 뒤집는다 — 매주 F로 자동 원복하고 상향은 매주 명시적 재승인이 있을 때만 유지.
2. 고용이 유지된 상태의 복귀다. 틀리면 바닥이 "고용 유지"가 아니라 "다음 소득원"이 되어 이 문서를 폐기해야 한다.
3. 단축근무 승인 기간이 8주를 덮는다. 4주만 승인되는 경우가 실제로 흔하므로, 연장 신청서를 0주차에 미리 제출하고 승인 여부를 4주차 타당성 검토의 입력으로 삼는다. 미승인이면 5주차부터 F 유지가 제도적으로 불가하므로 그 시점에 대안 A로 전환한다(거주성 검사만으로는 이 실패를 잡지 못한다 — 0주차에는 4주분 승인이 "가능"으로 보인다).
4. 임상 접점(주치의·EAP·상담)이 하나 있다. 틀리면 예외 경로에 수신자가 없어 경로가 허구가 된다. 0주차 검증 = 예약 1건 확보.
5. 근태·수면 기록이 이미 존재해 새 계측 없이 신호를 읽을 수 있다. 틀리면 신호가 자기보고로 후퇴한다. 대체 = 대리인 육안 관측 2개(체크 참석, 종료 시각 목격).

## 접근 및 단계

주차 라벨은 캘린더가 아니라 의존의 투영이다. N주차 상태는 N−1주차 프로브 결과의 함수이며, 표의 선행 조건 열이 그 함수다.

**전환 비대칭(전 주 공통)**
- 하향: 대리인이 다음 중 1건을 관측하면 즉시, 본인 동의 없이 F 원복(사후 통보) — 예정 종료 시각 초과 2일 / 주간 체크 결석 1회 / 수면 기록 4시간 미만 3일 연속 / 진료 취소 1회. 전부 기록·관측 기반이며 자기평가 항목은 없다.
- 상향: 주 1회 한 칸. 조건 = 직전 주 신호 0건 + 프로브 정상 + 대리인 동의. 한 칸 = 하루 30분 또는 회의 1건 또는 트랙 0.5종(자의값, 3주차 실측으로 대체).
- 상향 후 48시간 내 신호 1건 → 자동 원복, 그 상향은 2주 잠금.

**하향 가격표(0주차 작성, 빈칸은 채우지 않는다)**

| 전환 | 무료 창 | 마감 후 비용 | 확인 담당·시점 |
|---|---|---|---|
| 정상 → F | 상시 | 없음 | — |
| F → 병가 | 잔여 병가 N일: 확인 필요 | 무급 전환 여부: 확인 필요 | 대리인, 0주차 |
| 병가 → 휴직 | 리드타임·진단서 요건: 확인 필요 | 급여 비율 하락: 확인 필요 | 대리인, 0주차 |

각 창의 잔여가 2주 남으면 대리인에게 캘린더 알림이 간다(0주차 등록). 이 알림 없이 "즉시·자동 하향"은 문장일 뿐이다.

**비발화 재해석과 능동 프로브.** 하향이 한 번도 발화하지 않은 것은 회복의 증거가 아니라 탐지 실패 의심이다. 프로브는 새 계측을 만들지 않는다 — ① 주간 체크 완료율(대리인 기록) ② 합성 유입 테스트: 3주차·6주차에 대리인이 통보 없이 가짜 요청을 보내고, 본인이 직접 수락하면 라우팅 게이트 실패 ③ 근태 로그의 종료 시각 초과 분.

**바닥 함정.** 하향이 싸면 기계는 바닥에 정착한다. 3주 연속 상향 0이면 다음 주에 계획 타당성 검토 30분을 강제한다(N=3은 파생값 — 8주 창 안에서 최소 1회 돌아야 하고 N=4면 돌지 않을 수 있다). 결론 선택지에 (a) 유지 (b) 바닥 재설정(더 낮게) (c) 이 계획 폐기 → 휴직 전환이 모두 포함된다. (a)만 나올 수 있는 검토는 장식이다.

| 주(투영) | 선행 조건 | 추가분 | **플랜 B(축소)** | 검증 |
|---|---|---|---|---|
| 0 | 없음 | 위임 서명, 인사 5문 질의 + 연장 신청, 권한 제거, 프로브·알림 등록, 트랙 지명, 가사 재배분 합의 | 서명 불가 → 가정 1의 대체 경로로 착수 | 6개 산출물 첨부 |
| 1 | 0주차 완료 | 없음, F 확립만 | 4시간을 이틀 이상 못 채우면 임상 경로 판단 + 바닥 재설정 | 근태 로그 5일분 |
| 2 | 1주 신호 0 | 하루 30분 | F 원복, 상향 2주 잠금 | 대리인 기록 |
| 3 | 2주 신호 0 | 회의 1건(비동기 불가한 것만), 합성 테스트 1회 | 회의 0 복귀, 텍스트 요약 대체 | 테스트 결과 |
| 4 | 3주 결과 + 연장 승인 여부 | 3주 연속 상향 0이면 타당성 검토 강제, 아니면 트랙 0.5 | 결론이 (b)/(c)거나 연장 미승인이면 그 주에 실행 | 회의록 |
| 5 | 4주 신호 0 + 프로브 정상 | 소유권 1건 인수 | 반납을 매니저가 대행(본인이 협상하지 않음) | 반납 기록 |
| 6 | 5주 신호 0 | 합성 테스트 2회차, 병가 잔여 창 알림 확인 | 게이트 실패 시 라우팅 자동응답 재설치 | 테스트 결과 |
| 7 | 6주 프로브 정상 | 9주 이후 정상 상태 초안을 매니저가 작성 | 초안 없으면 F를 기본값으로 연장 | 초안 문서 |
| 8 | 7주 산출 | 완료 판정, 위임 연장 여부 결정 | 미달이면 위임 8주 연장이 기본값 | 판정 체크리스트 |

## 대안과 기각 사유

- **A. 즉시 3개월 전면 휴직.** 기각: 제도·소득 확인 전의 비가역 하향이고 복귀 부담을 3개월 뒤로 미룬다. 부활 조건: 거주성 검사가 "8주 F 불가"이거나, 단축근무 연장이 미승인이거나, 4주차 검토가 (c)를 내면 즉시 — 이미 하향 경로에 배선돼 있다.
- **B. 일일 자기 체크인 상태기계.** 기각: 점검 비용이 남은 슬랙을 넘고 트리거가 자기판단에 의존한다. 부활 조건: 상향 4칸 이상 + 기존 앱의 자동 수집으로 30초 내 끝나는 형태가 될 때.
- **C. 고정 시간 사다리(2→4→6→8시간).** 기각: 회복은 단조 상승이 아니며 고정 증분은 상향 판단을 캘린더에 위임한다. 부활 조건: 3주 연속 신호 0 + 프로브 정상일 때 상향 자동화로 제한 도입.

## 리스크 & 완화

- 대리인이 관계 부담으로 집행하지 않는다 → 위임문에 "미집행도 기록" 조항, 미집행 2회면 대리인 교체가 기본값.
- 평가·수습 불이익(확인 필요) → 제외 규정이 없으면 8주 산출물 기대치를 0주차에 문서로 낮춰 합의.
- 근무 축소가 가사·돌봄 부담으로 상쇄된다 → 새 규칙을 더하지 않고 0주차 재배분 합의 1회로 처리. 같은 이유로 일일 기록 규칙은 삭제했다.
- 프로브가 부담이 된다 → 기존 로그 2개 + 합성 테스트 2회로 상한, 새 도구 도입 금지.
- 동료의 게이트 우회와 9주 이후 재발 → 팀 채널 공지 1회로 라우팅을 공지하고, 위임 연장이 기본값·해지가 예외다.

## "완료"의 판정 기준

1. **하향 트리거 발화 건수와 각 건의 기록(관측자·신호·집행까지 걸린 시간)이 남아 있다. 발화 0건이면 완료가 아니라 탐지 실패로 판정하고 프로브 결과와 교차 판독한다.**
2. 합성 유입 테스트 2회 중 2회에서 요청이 본인 수락 없이 매니저로 라우팅됐다. 1회라도 수락하면 게이트 실패로 기록한다.
3. 주간 체크 완료율 ≥ 7/8(파생: 결석 1회는 그 자체가 하향 신호이므로 2회 이상은 운영 실패), 대리인 기록으로 판독.
4. 인사 질의 5항목의 서면 답과 연장 승인 여부가 첨부되고 거주성 표의 빈칸이 0이다.
5. 근태 로그의 종료 시각 초과 건수와 24시간 내 하향 집행 기록이 1:1로 대응한다.

## 프레임 이탈 / 관성 회귀

- 주차 표는 8행 오름 배열로 읽힌다. 선행 조건 열로 의존을 적었지만 표 형식 자체가 상승 서사를 암시한다 — 이 문서에서 가장 약한 지점. 특히 5주차 "소유권 1건 인수"와 7주차 초안은 프로브 통과의 함수인데도 캘린더 위치를 얻었다.
- 4시간·30분·1종은 도메인 근거 없는 초기값이다(§시작점에 자의값으로 표시). 판단을 대체하려면 숫자가 필요했고 근거는 만들지 않았다.
- 하향 가격표 절반이 "확인 필요"로 비어 있다. 추정치를 넣으면 허구가 되므로 비웠지만, 결과적으로 "즉시·자동 하향"의 성립이 0주차 인사 답변에 인질로 잡혀 있다.
- 주 1회 15분 1:1은 프레임이 요구한 것이 아니라 조직이 소화 가능한 관행이라 골랐다.
- 리뷰어라면 §완료 판정 2번을 공격하겠다. 표본 2회로 라우팅 게이트를 판정하면 실패를 놓칠 확률이 크다. 늘리면 프로브 부담이 프레임의 실패모드로 들어가므로 2로 두었고, 이 트레이드오프는 해결하지 못했다.
