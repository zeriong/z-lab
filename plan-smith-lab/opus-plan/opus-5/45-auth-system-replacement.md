# 레거시 모놀리스 인증 시스템 교체

- 추론 프레임: risk-matrix / 스타일: opus-style
- 한 줄 요약: 실패 시나리오를 확률×피해로 정렬하고, 비가역 피해는 확률과 거래하지 않는다는 정책을 채점 전에 선언한 뒤, 절단선 위 5건만 덮고 나머지는 "의도적 미커버"로 봉인한다.

## 프레임이 요구하는 시작점 — 척도 정의 → 채점 → 절단선(봉인) → 그 다음에야 대책

이 과제를 보자마자 떠오른 습관은 "신 아키텍처 → 마이그레이션 3단계 → 마지막에 리스크 표"였고, 프레임은 정확히 그것을 금지한다. 대책을 먼저 떠올린 사람은 자기 대책이 1위가 되도록 점수를 조정한다. 그래서 이 문서는 척도 → 점수 → 절단선을 먼저 확정하고 **봉인**한 뒤(작성자 외 1인이 표에 서명, 이후 변경은 변경 로그에 기재), 그 아래에서만 대책을 설계한다.

### 피해 척도 D (앵커만 정의 — 두 사람이 독립 채점 가능하고, 채점 입력을 조달할 수 있어야 한다)

- **D5** = 계정 소유권 또는 자격증명이 제3자에게 이전되고 **사후 식별도 회수도 불가**(누구 계정이 언제 넘어갔는지 감사로그로 특정 불가). 채점 입력: 감사로그 스키마 조회, 소유권 이전 경로(비밀번호 재설정·대행 로그인) 목록.
- **D4** = 되돌릴 수 있으나 **롤백만으로는 원상복구되지 않는다**(사용자 재로그인, 앱 재배포, 데이터 재생성 필요).
- **D3** = DAU 5%(임의 경계) 미만 영향, 재시도·재배포로 자동 복구. 채점 입력: DAU 대시보드, 영향 경로 트래픽 비중.
- **D1** = 내부 로그에만 남고 사용자 영향 0. D2는 D1과 D3 사이.

### 확률 척도 P — 기준 시제 선언

점수는 **"대책 없이 관행대로 진행할 때, 6주 병행 창 안에 1회 이상 발생"** 을 뜻한다. P5 ≥ 80% / P3 ≈ 30% / P1 < 5%. 구간 경계는 **임의 선언**이며 1% 코호트 2주 실측으로 교체한다(S7). 6주 창도 **임의값**(스프린트 3개)이고 이중쓰기 실소요 측정으로 교체한다.

### 비가역 피해 정책 (채점 전 선언, 택 1)

**사전식 우선**을 택한다 — D5 항목은 확률과 거래하지 않고 무조건 최상위 티어다. 순수 곱셈이 아니다. 이 선택이 뒤집은 결정: 곱셈이면 L1(3×5=15)이 M1(5×4=20) 아래로 내려가 세션 불일치가 1순위가 됐을 것이다. 프레임의 "선 아래 비가역 항목에 부활 트리거" 조항은 이 정책으로 **구조적으로 충족**된다(비가역 항목은 선 아래로 갈 수 없다). 대신 그 의무를 비가역 하위경로를 가진 D4 항목(M3, 선 아래 R6)에 적용한다.

한 가지를 명시한다: **임시 마이그레이션 스크립트·자격증명 덤프 잔존은 별건 항목으로 세우지 않고 L1의 확률 근거로 흡수했다.** 별건화하려면 D5 정의를 넓혀야 하고, 넓히면 최상위 티어가 4건이 되어 정렬 자체가 사라진다.

## 문제 정의 / 목표

모놀리스에 박힌 자체 인증(세션 테이블 + 자체 해시 + 인프로세스 권한 체크)을 분리된 인증 시스템으로 교체한다. 목표는 "신 시스템 가동"이 아니라 **교체 창 동안 비가역 피해 0, 가역 피해는 절단선 위 항목만 통제**다.

## 순위표 (봉인 대상)

**비가역 티어 — 확률과 거래 금지**

| 순위 | 시나리오 | P | D | 확률 근거 |
|---|---|---|---|---|
| L1 | 마이그레이션 중 계정 탈취 — 이중쓰기·해시 재암호화·완화된 복구 플로우·임시 스크립트/덤프가 동시 존재 | 3 | 5 | **6주 병행 창이 열려 있다** |

**곱셈 티어**

| 순위 | 시나리오 | P | D | P×D | 확률 근거 |
|---|---|---|---|---|---|
| M1 | 세션 이중화 불일치 — 로그아웃·권한회수·비번변경이 반대쪽에 전파되지 않음 | 5 | 4 | 20 | **6주 창** + 저장소 2개 |
| M2 | 전 사용자 강제 로그아웃 — 세션 표현 형식 교체로 기존 세션 일괄 무효 | 4 | 4 | 16 | 현행 세션이 서버측 행 참조라 신 형식으로 재해석 불가(세션 테이블 스키마 조회로 확인) |
| M3 | 구버전 모바일 앱 영구 로그아웃 — 토큰 포맷 변경 + 스토어 심사 지연 | 3 | 4 | 12 | **6주 창** 내 앱 배포 미완 |
| M4 | 롤백 시 신규 자격증명 소실 — 커토버 후 생성·변경분이 구 스키마에 없음 | 3 | 4 | 12 | 역방향 기록 부재 |
| **절단선 = 12** | 동시 대응 능력에서 도출: 엔지니어 2명 × 항목당 2주 = 동시 5건, 1슬롯은 위상 예외에 배정 → 4건 → 표에서 읽은 값. **점수에서 도출된 값이 아니다.** | | | | |
| R7 | 야간 인시던트 대응 지식 공백 | 3 | 3 | 9 | 신 시스템 운영 경험 0 |
| R8 | 인증 지연 → 전 요청 장애 | 2 | 4 | 8 | 인증이 모든 요청의 선행 |
| R6 | 규제·감사 (해시 알고리즘, 처리 위탁 신고, 로그 보존) | 2 | 4 | 8 | 법무 질의 미완 |

선 아래 3건은 **의도적 미커버**다. 부활 규칙을 지금 확정한다: 상위 항목 종료로 슬롯이 열리면 점수순 → 동점이면 D 큰 항목 → 그래도 동점이면 비가역 하위경로 보유 항목. 결과는 R7 → R6 → R8. 트리거 없는 재논의는 절단선 표류다.

**위상 예외 (1회, 소진)** — R7의 계측 부분(세션·토큰 인벤토리 + 폐기 전파 감사로그)만 **자원 배정 우선권**을 받는다. L1의 D 판정과 M1의 검증이 이 계측 없이는 성립하지 않으므로 "하위 항목이 상위 대응의 인프라" 조건을 만족한다. 예외는 1/1 소진했고, 이후 어떤 항목도 예외로 순서를 바꾸지 않는다.

## 명시적 가정

- **모든 세션·토큰을 서버측 단일 폐기 채널로 통과시킬 수 있다.** 틀리면 L1·M1 대책이 전부 무효다. 최저비용 조기 검증: 토큰·세션 검증 코드 경로 수를 그렙으로 센다(반일, S0 이전). 폴백: 토큰 TTL을 5분(임의값)으로 축소해 "폐기 지연 ≤5분"을 수용하고 그 지연을 넣어 M1을 재점수한다(S7의 입력).
- 구 시스템을 6주간 살려둘 수 있다. 틀리면 M4의 D가 5로 올라 티어 구성이 바뀌고 표를 다시 채점해야 한다.
- DAU·세션 통계를 조회할 수 있다. 틀리면 D가 독립 채점 불가가 되어 프레임 자체가 무효 — 그래서 계측이 선행이다.
- 감사로그 보존 기간이 현행 규제를 충족한다. 틀리면 R6가 선 위로 올라온다.

## 접근 및 단계 (의존 순서. 번호는 시간표가 아니다)

- **S0 · 계측** (위상 예외 항목) — 선행 없음. 세션·토큰 인벤토리와 행위자 식별자를 남기는 폐기 감사로그를 세우고, 병렬로 법무 질의 1건(위탁 신고 필요 여부, 과징금 상한)을 보내 R6의 채점 입력을 조달한다. 검증: 무작위 활성 세션 20개가 신·구 양쪽에서 동일 식별자로 매칭 20/20, 폐기 이벤트 1건 주입 시 행위자와 함께 기록됨. 봉사 대상: L1 판정, M1 검증.
- **S1 · 창 길이를 0으로** (L1의 1단계는 난이도 축소다) — 선행: S0 인벤토리. 일괄 해시 재암호화를 폐기하고 **로그인 시 지연 재해시**로 바꿔, 스크립트가 복호 가능한 자격증명을 보유하는 시간을 없앤다. 검증: 자격증명 보유 스크립트 0건, 보유 시간 0초. ("어려워서 나중"이 아니라 난이도 축소를 그 항목의 1단계로 둔다.)
- **S2 · 복구 플로우 동결** — 선행: 독립(S1 실패와 무관하게 유효). 창 동안 비밀번호 재설정·매직링크 강도를 완화하지 않고, 관리자 대행 로그인은 2인 승인으로 잠근다. 검증: 지정 인원 2명이 타인 계정 인수를 10회(임의 표본) 실제 시도 — 성공 0건 **그리고** 10/10이 시도자 식별자와 함께 감사로그에 남는다. 성공 0은 매체 제거로 자동 충족되므로 실측 지표는 기록률이다. (적대적 검증 장치는 failure-first 프레임에서 이 항목에만 차용.)
- **S3 · 단일 폐기 채널** — 선행: S0. 구 시스템의 세션 검증을 신 시스템 introspection 프록시로 대체해 저장소를 하나로 만든다. 검증: 세션 20개 폐기 → 구 경로에서도 30초 내 401, 20/20.
- **S4 · 세션 승계** — 선행: S3. 구 세션 쿠키를 신 토큰으로 무중단 교환한다. 검증: 1% 코호트 재로그인율이 기준선 +2%p 이내. (1%는 임의 초기값 — 첫 코호트의 CS 문의 전환율 실측으로 CS 리드가 교체.)
- **S5 · 토큰 포맷 하위호환** — 선행: 독립(S3과 병렬). 구버전 앱이 쓰는 포맷·엔드포인트를 유지 기한과 함께 남긴다. 검증: 최소 지원 버전 2개 로그인 회귀 통과, 미지원 버전 사용자 비중을 수치로 기록.
- **S6 · 롤백 경로** — 선행: S3. 커토버 후 생성·변경된 자격증명을 구 스키마로 역기록한다. 검증: 스테이징 롤백 리허설에서 커토버 후 만든 계정 10건이 롤백 후 로그인 10/10.
- **S7 · 재점수 게이트** — 선행: S1~S6. 기준 시제를 **"S0~S6 적용 후, 1% 코호트 실측값 기준"** 으로 재선언해 다시 채점한다. 커토버는 M1이 선 아래(P×D < 12)로 내려갔을 때만 진행하고, 아니면 창 연장 또는 철회 — **기본값은 철회**다.

## 대안과 기각 사유

- **빅뱅 커토버(병행 없이 전원 강제 재로그인)** — L1의 확률 근거를 제거하지만 M2를 확정 발생시키고 롤백 경로가 사라져 M4의 D가 오른다. 부활 조건: 활성 세션 90%가 24시간 내 자연 만료되고 미지원 앱 사용자가 1% 미만으로 **측정**될 때(두 임계는 임의값 — 자연 만료율 실측 후 재설정).
- **외부 IdP 전면 위탁** — 순위표를 바꾸지 않는다(위험은 목적지가 아니라 창에 있다) + R8의 D를 올린다. 부활 조건: 법무 질의 결과로 R6가 선 위로 올라오면 재평가.
- **영구 병행(shim 유지)** — M1의 P를 상수 5로 고정한다. 부활 조건: S3 완료로 구 시스템이 읽기 전용 프록시가 되어 데이터 이중화가 사라진 뒤.

## 리스크 & 완화

- **역채점** — 채점자가 설계자다. 표를 S1 이전에 봉인하고 변경은 로그에 남긴다.
- **재점수 시 시제 미갱신** — S7 표 머리에 시제 문장을 필수 항목으로 둔다.
- **예외 2회째 요구** — 기본 거부(1/1 소진).
- **진짜 적** — L1·M1·M3이 같은 근거 문장("6주 병행 창이 열려 있다")을 인용한다. 단일 최대 레버는 창 길이 축소이고 S1이 그것이다.
- **잔여 위험** — S5는 스토어 심사 시간을 통제할 수 없다. 값 대신 관측 해상도만 통제한다(미지원 버전 접속 비중 일일 보고).

## "완료"의 판정 기준

1. **활성 세션 20개를 신 시스템에서 폐기하면 구 시스템 경로에서도 30초 내 전부 401이다(20/20, 실패 1건이면 중단).** 측정: SRE가 운영 스크립트로 무작위 표본을 뽑아 감사로그 타임스탬프 차로 계산. 20은 임의 표본(허용 실패 0), 30초는 캐시 TTL 실측값으로 교체.
2. 인수 시도 10건 전부가 시도자 식별자와 함께 감사로그에 기록된다(성공 0은 별도로 세지만 자동 충족되므로 판정 근거가 아니다).
3. 커토버 후 7일 재로그인율이 직전 4주 기준선 +2%p 이내. 측정: 데이터팀, 로그인 이벤트 로그.
4. 롤백 리허설에서 커토버 이후 생성 계정 10건이 롤백 후 로그인 10/10.
5. S7 재점수표가 시제 문장과 함께 존재하고, 선 아래 3건이 "의도적 미커버 + 부활 규칙"으로 기재돼 있다.

## 프레임 이탈 / 관성 회귀

- **위상 예외를 계측에 썼다**: 규칙 조건은 만족하지만 "관측부터 깔자"는 내 기본 습관과 결론이 같다. 습관과 규칙이 일치하는 곳에서 규칙은 아무것도 검증하지 않는다.
- **S1~S7 번호가 사다리로 읽힌다**: S2는 S1과 독립이고 S5는 S3과 병렬인데 번호가 의존을 과대 표현한다.
- **가장 약한 절은 D 척도**: D5를 좁혀 비가역 티어를 1건으로 만들었다(덤프 잔존을 L1에 흡수한 것이 그 결과다). 정의를 한 문장 넓혀 별건화하면 티어가 4건이 되고 순서가 사라진다 — 순위가 정의문의 폭에 의존한다.
- **리뷰어라면 R6(규제) D4를 공격하겠다**: 법무 질의 전이라 채점 입력이 없었고 선 아래로 떨어지는 결과가 편했다. 질의를 S0 병렬 항목으로 넣어 한 번 고쳤으나, 결과가 오기 전까지 이 순위는 미확정이다.
