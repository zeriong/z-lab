# 30초 플레이 루프 하이퍼캐주얼 게임 — 감정 시퀀스 역설계

- 추론 프레임: emotion-curve
- 한 줄 요약: 결정적 감정은 30초 루프 **밖**(사망~재탭 사이 1.5초)에 있다 — 그 갭을 최우선 설계 단위로 잡고, 갭을 침해하는 관행(재시도 갭 광고, 레벨 선택 화면)을 기각한다.

## 1. 프레임이 요구하는 시작점 — 곡선부터 그린다

### 1-1. 런 내부 곡선 (목표 30초 / 중위 22초)

```
긴장
 5 |                                     ●사망
 4 |                          ╱‾╲╱‾╲╱‾╱
 3 |              ╱‾╲╱‾╲╱‾╲╱
 2 |      ╱‾╲╱‾╲╱                                 ╱ ← 재탭
 1 |  ╱                                    ╲___╱
 0 +--┬-----┬-----┬-----┬-----┬-----┬------●----┬----→
    0s    4s    8s   12s   16s   20s    24s  +1.5s +1.9s
        [진입]  [톱니: 긴장↗ + 게이트마다 미세 해소]   [밸리]
```

| 구간 | 감정 | 관측 가능한 발생 조건 (감정은 구현 불가) | 이를 만드는 메카닉 | 심는 시점 |
|---|---|---|---|---|
| 0~2s 진입 | 무긴장·즉시성 | 포그라운드→첫 유효 입력 ≤2.0s, 튜토리얼 화면 0개 | 카운트다운 없음, 첫 게이트는 실패 불가 폭 | 런 시작 전 |
| 2~24s 톱니 | 긴장 ↗ | 벽 최근접 거리 단조 감소 + 3채널 동시 표시(색 온도·햅틱·명도) | 게이트 간격 4~6s→2s 점감, 스크롤 속도 점증 | 런 중 |
| 게이트 통과 | 미세 해소 | 통과 후 0.4s 동안 근접도 지표가 실제 하강(로그로 확인) | 스코어+1, 플래시, 피치 1단 상승 | 런 중 |
| 사망 t=0 | 절정 | 0.35s 슬로모 + 사망 좌표 마커 고정 | 시간 스케일 0.25 | 런 중 |
| +0.35~1.5s **밸리** | 아쉬움 | ① 귀인 명료성: 사인이 단일하고 마커로 지목됨 ② 목표 근접도 가시화: 최고기록까지 남은 거리를 게이지가 1.15s 채우고 멈춤 | 근접 실패(최고기록 90%↑)와 비근접 실패는 **다른 밸리 화면** | **런 시작 이전** — 계측(마지막 게이트 시각·사망 좌표)이 먼저 없으면 게이지가 거짓말을 한다 |
| +1.5s~ | 재도전 욕구 | 탭→첫 조작 가능 프레임까지 마찰 ≤350ms | 전면이 재시작 버튼. 메뉴·보상·광고 없음 | 런 시작 전 |

> **숫자 규약:** 이 문서에서 파생된 값은 **350ms 하나뿐**이다(씬 재로딩을 금지하고 상태 리셋만 허용할 때의 상한 — 이 값이 씬 구조를 역제약한다). 개별 태그가 없는 **모든** 시간·비율·임계값은 임의 선언 + 수명한정이며, 첫 외부 플레이테스트(N=50 세션)의 로그로 교체한다. 측정자=클라이언트 이벤트 소유자.

### 1-2. 런 간 봉투 곡선 (한 세션 8~15런)

단조 상승이 아니다. 1~2런 탐색 → 5~7런째 최고 긴장 → 이후 **하강**(피로)이 정상이며, 이탈 직전 2~3런의 긴장 저하는 고칠 결함이 아니다.

- 설계된 하강 ① **좌절 골짜기** — 연속 실패 3회 시 난이도 시작 단계를 1단 되돌린다. **표시하지 않는다.** (3회는 파생 시도 실패: 세션 런 수 분포 없이는 도출 불가. 수명한정 교체점 = "연속 실패 n회 후 이탈률" 곡선의 무릎)
- 설계된 하강 ② **세션 종료** — 강제 복귀 장치(알림·일일 보상·연속 출석)를 두지 않는다. 이탈은 곡선의 끝이다. 생존 스펙: 이탈 시점의 최고기록이 영속화되어 있고, 재진입 첫 화면이 최고기록이다.

### 1-3. 정의역 회의

30초를 설계 단위로 잡으면 재도전 욕구가 설계 대상에서 빠진다. 그 감정은 사망~재탭 1.5초와 세션 간(앱을 다시 여는 순간)에 발생한다. 따라서 단위는 "런"이 아니라 **"런 + 갭"**이고, 갭에 개입하는 요소는 담당 곡선 구간을 대지 못하면 반려된다. 세션 간 장치는 영속 최고기록 하나로 제한한다.

## 2. 문제 정의 / 목표

목표는 "재미있는 게임"이 아니라 §1의 곡선이 관측 데이터로 재현되는 것이다. 판정 대상 명제는 **밸리(아쉬움 연출)가 재도전율을 올린다**이며, 반증되면 밸리 UI를 삭제한다(§8-1).

## 3. 명시적 가정

1. **근접 실패의 인지(아쉬움)가 재탭의 주 원인이다.** — 틀리면 §1-1 밸리 행, S4, §8 판정이 전부 무효(계획의 절반). 최저비용 조기 검증: 밸리 유/무 2빌드를 사내 20명에게 1일 노출하고 "3초 내 재시도율"만 비교. 폴백: 밸리를 0.35s 슬로모만 남기고 삭제, 아쉬움은 정적 텍스트 한 줄로 축소하고 마찰을 150ms까지 내린다.
2. 단일 입력(탭)이라 학습 비용이 사실상 0이다 — 틀리면 진입 구간이 무긴장이 아니라 혼란이 되고 S7에 온보딩 콘텐츠가 추가된다.
3. 저사양 기기에서 입력→시각 반응 ≤100ms가 가능하다 — 틀리면 긴장의 발생 조건(3채널 표시)이 붕괴하므로 색·명도를 버리고 햅틱 중심으로 재배치한다.
4. 세션당 8~15런이 나온다 — 틀리면 §1-2 봉투의 시간축이 어긋나고 완화 트리거를 재도출해야 한다.

## 4. 접근 및 단계 (선행조건 = 소비하는 산출물)

| 단계 | 선행조건 | 하는 일 | 검증 | 담당 곡선 구간 |
|---|---|---|---|---|
| S0 | 없음 | 이벤트·저장소 스키마 확정: 런 로그(사망 좌표, 마지막 게이트 시각, 최고기록 대비 %), 연속 실패 카운터, 영속 최고기록 | §8의 판정 문장을 이 필드만으로 계산 가능한지 표로 대조 | 전 구간(밸리·세션 간의 물적 근거) |
| S1 | S0 | 코어 런 루프: 입력→상승/하강→충돌 | 30초 도달 가능한 시드 존재. 저사양 기기 입력 지연 ≤100ms | 진입·톱니 |
| S2 | S1 | 게이트 + 미세 해소(§1-1 3행) | 통과 직후 0.4s 근접도 하강이 로그에 보임 | 톱니의 이빨 |
| S3 | S1 (S2와 병렬) | 근접도 3채널 가시화 | 사망 전 2초 지표 단조 증가, 색 단독 표현 0건 | 톱니의 상승 |
| S4 | S0, S1 | 밸리(§1-1 5행) + 전면 탭 리셋 | 마찰 실측 ≤350ms, 근접/비근접 화면이 다르게 렌더 | 밸리 |

| S6 | S4 | 수익화: 콜드스타트 1회 인터스티셜 + 자발적 부활 리워드 | **재시도 갭 구간 광고 노출 이벤트 0건** | 세션 경계(갭 아님) |

## 5. 곡선 밖 요구 스윕 (공란은 결함)

| 항목 | 판정 | 근거 / 트리거 |
|---|---|---|
| 오디오 + 햅틱 | build | 긴장 3채널 중 2개. 무음 기기 대비로 햅틱 필수 |
| 최고기록 영속(로컬) | build | 세션 간 아쉬움의 유일한 물적 근거 |
| 온보딩 | build (화면 0개) | 첫 게이트를 실패 불가 폭으로 만드는 것이 온보딩 |
| 저사양 프레임·입력 지연 | build | 폴리시가 아니라 긴장의 발생 조건 |
| 접근성(한손·색약) | build | 근접도의 색 단독 표현 금지 |
| 아동 트래픽 규제(연령 게이트·광고 SDK 동의) | build 최소 | 연령 등급 + 동의 플래그. 상세 흐름 defer — 트리거: SDK 계약 서명 |
| 스토어 자산(아이콘·15초 영상) | build | 진입 구간은 스토어에서 시작한다 |
| 리더보드/소셜 | defer | 트리거: §8 판정 통과 + 세션 중위 런 수 ≥8 |
| 스킨/IAP | defer | 트리거: 자발적 부활 사용률 ≥15% |
| 클라우드 저장 | defer | 트리거: 리더보드 착수와 동시 |

## 6. 대안과 기각 사유

1. **30초 고정 타이머 런** — 기각: 종료 원인이 시간이면 귀인이 흐려져 아쉬움의 발생 조건 ①이 성립하지 않는다. 부활 조건: §8-1이 밸리를 기각하면 고정 길이 + 스코어 최대화로 전환.
2. **스테이지/레벨 선택 구조** — 기각: 선택 화면이 갭의 마찰 예산(§1-1 최종 행)을 초과한다. 부활 조건: 세션 중위 런 수 >15로 권태가 관측되면 레벨 메타를 **세션 경계에만** 삽입.
3. **재시도 갭 인터스티셜(장르 표준 관행)** — 기각: 곡선의 결정적 구간을 광고로 채운다. 관행과의 충돌을 감수한다. 부활 조건: 세션 경계 수익만으로 CPI 회수 불가 판정 시, "3초 내 재시도율 하락 ≤5%p" 실측을 조건으로 한 제한 도입.
4. **복귀 알림·연속 출석 보상** — 기각: §1-2 하강 ②를 결함으로 취급하며, 개인 신호가 아니라 달력으로 발화한다. 부활 조건 없음(설계 원칙).

## 7. 리스크 & 완화

- **곡선의 장식화**(최대 리스크): 논의가 메카닉 튜닝으로 회귀 → 기능 제안서에 "담당 곡선 구간" 필드를 필수로 두고, 못 대는 제안은 반려.
- 수익화 압력이 갭을 침식 → 갭 광고 0건을 스펙·계약 문구에 고정하고 노출 위치를 이벤트로 감시(S6 검증란).
- 은닉 완화(S5)의 공정성 → 완화 폭 1단 상한, 게이트 점수 가치 불변. 리더보드 도입 시 재검토.
- 판정이 튜닝 실패와 가설 실패를 구분 못 함 → 근접/비근접 코호트 대조로 가설 축을 분리(§8-1).
- 상승 서사 회귀: 봉투의 하강을 "고치려는" 유혹 → §6-4에서 사전 기각.

## 8. "완료"의 판정 기준 (곡선을 반증할 수 있어야 한다)

측정 도구: S0의 클라이언트 이벤트 필드(`death_pos`, `pct_of_best`, `retry_latency_ms`, `run_index`). 측정자: 클라이언트 이벤트 소유자. 대상: 첫 외부 플레이테스트 N=50 세션.

1. **반증 문장(필수):** 근접 실패 코호트(최고기록 90%↑)와 비근접 실패 코호트의 "사망 후 3초 내 재시도율" 차이가 **±2%p 안에 들면 밸리 UI(S4)는 기각되고 삭제된다.** 이 문장은 계획의 어떤 차단 장치로도 자동 충족되지 않는다 — 밸리를 잘 만들어도 차이가 없으면 실패다.
2. 전체 "3초 내 재시도율" ≥70%.
3. 실기기 3종에서 재시도 마찰 ≤350ms, 입력 반응 ≤100ms.
4. 재시도 갭 광고 노출 0건, §5 표 공란 0개.
5. 세션 런 수 분포의 중위가 8~15 밖이면 §1-2 봉투를 다시 그린다(완료가 아니라 재설계 트리거).

## 프레임 이탈 / 관성 회귀

- §1-2 하강 ②의 생존 스펙이 한 문장(영속화 + 재진입 첫 화면)뿐이다. 런 내 밸리는 발생 조건을 두 갈래로 쪼갰는데 세션 간 하강은 못 쪼갰다 — 세 감정 중 가장 얇고, 리뷰어라면 여기를 판다.
- §5의 규제 행은 build 최소 + defer이며 실질은 회피다. 트리거로 방어했을 뿐 동의 흐름 설계는 없다.
- §1-2의 "연속 실패 3회"는 파생을 시도하고 실패했다. §1-1 숫자 규약이 실토하듯 파생된 값은 350ms 하나뿐이고, 곡선의 시간 좌표는 전부 가설이다.
- 관성: 과제를 보고 "코어 루프 → 난이도 → 리텐션 → 수익화"라는 장르 관례 순서를 먼저 떠올렸다. §4에 그 잔재로 S6이 뒤에 있다(S4 의존으로 정당화되긴 한다).
