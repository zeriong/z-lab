# 개발자 대상 유료 뉴스레터 런칭 계획

- 추론 프레임: unit-economics
- 한 줄 요약: 일반 개발자 대상 9,900원/월은 손익분기 341명이 필요해 도달 범위 밖이므로 기각하고 니치 한정·월 2회·29,000원 구조(N\*=57)로 시작한다 — 성립 조건은 니치 리스트 1,200명 기준 유료 전환율 **4.8% 이상**이며, 이 플랜의 실체는 전환율·이탈률 두 변수의 측정 장치다.

## 프레임이 요구하는 시작점 — 구독자 1명의 원장

단위 = 유료 구독자 1명 / 1개월. 표시가는 VAT 포함으로 읽어 공급가는 ÷1.1, 수수료는 결제 총액 기준(PG는 총액에 붙는다). 두 안을 같은 기준으로 세운다.

| 항목(원/월) | 원안 A: 일반·주 4회·9,900 | 피벗 P1: 니치·월 2회·29,000 |
|---|---|---|
| 공급가 (표시가 ÷1.1) | 9,000 | 26,364 |
| 플랫폼 10% + PG 2.9%+400원 | -1,677 | -4,141 |
| 발송·인프라 변동비 | -100 | -100 |
| **월 기여 m** | **7,223** | **22,123** |
| 고정비 = 제작시간×단가 + 툴 | 40h×60,000+60,000 = 2,460,000 | 20h×60,000+60,000 = 1,260,000 |
| **손익분기 구독자 N\*** | **341** | **57** |
| LTV (월 이탈 5%) | 144,460 | 442,460 |
| 허용 CAC 상한 = LTV/3 | 48,000 | 147,000 |

숫자 태그: 시간단가 60,000원/h **유도**(시니어 연봉 1.2억 ÷ 2,000h). 회당 제작 10h **수명 제한**(S2 타임로그로 교체). 월 이탈 5% **수명 제한**(S4 코호트 실측으로 교체). 플랫폼 10%·PG 2.9%+400원·툴 60,000원 **유도**(공시 요율, ESP 최소 요금+도메인). 환불 시 공급가는 반환되고 PG 고정수수료는 통상 미환급 → 환불 1건은 마진이 음수인 단위다; 월 환불율 3% **임의**(첫 3개월 실측 교체) → 실효 m ≈ 표값의 97%.

**부호 안정성 점검.** m의 부호는 뒤집히지 않는다 — 현금 변동비가 표시가의 16~17%뿐이다. 뒤집히는 것은 저자 시간을 실은 완전원가 마진이고 그것은 N과 시간단가에 의존한다. 따라서 "LTV/CAC 3.2배, 성립" 같은 점추정 판정은 쓰지 않고 가장 못 믿는 변수의 필요 임계값으로 반전한다.

- 원안 A: 12개월 리스트 4,000명 가정 시 필요 전환율 341/4,000 = **8.5%**. 일반 대상 벤치마크 2~5%(**수명 제한** — 자체 페이월 첫 4주로 교체) 상단 초과 → **성립 불가**.
- 피벗 P1: 필요 전환율 57/1,200 = **4.8%**. 니치 벤치마크 5~10%(**수명 제한**, 같은 실측 교체) 하단에 겨우 걸린다 → **성립 가능하나 여유 없음**. 여유가 없으니 이후는 성장 계획이 아니라 측정 계획으로 전개한다.

**숨은 통화.** 저자 시간은 위 고정비에 올렸다. 나머지 셋은 현금 원장에 안 나타나므로 게이트로 처리한다: 감정 노동(마감 연속성은 회수 불가 소모품 → 지연 2회 시 빈도 자동 인하), 평판 재고(유료화 후 품질 미달은 한 번에 인출·재입금 불가 → 무료 8회로 하한 공개 검증 후 과금), 정보원(사내 사례는 고용계약에서 인출 → S0에서 익명화 기준 문서화).

**재귀 ①: 오가닉 CAC = 0원의 착시.** 첫 원장이 유료 광고를 죽였으니(A3) 그 자리를 채운 오가닉에 원장을 다시 돌린다. 공개 글 1편 4h → 무료 100명(**임의**, S2 교체) → 전환 4.8% → 유료 4.8명 → 유료 1명당 0.83h = 시간 CAC 50,000원, LTV 대비 8.8배. 현금은 넉넉하지만 이 시간은 제작 시간과 **같은 지갑**이다: 주 4회(40h) + 성장 글 4편(16h) = 56h > 부업 슬랙 40h. 구속 조건은 현금이 아니라 시간이다 → **발행을 주 1회에서 월 2회로 내렸다.** 같은 니치 가격에서 주 4회면 고정비 2,460,000원 ÷ m 22,123 = N\* 111인데 월 2회는 57이다(툴 60,000원이 고정이라 정확히 절반은 아니다). 동시에 월 20h가 성장에 배정된다. 정석은 주간 발행이지만 원장이 정석을 기각한다.

**재귀 ②: 지정 기본 피벗의 스텁 원장.** S4 철수 분기의 기본값 P3(무료+스폰서십)은 단위가 구독자에서 **1회 발행 슬롯**으로 바뀐다. CPM 40,000원(**임의**, 스폰서 견적 2건으로 교체) × 5,000구독 = 슬롯당 200,000원 × 월 2회 = 400,000원 < 고정비 1,260,000원 → 리스트 15,000명 필요. P3은 쉬운 길이 아니라 규모 요구가 3배인 다른 사업이다.

**성립까지의 시간.** 판정까지 9개월(무료 8회 2개월 → 페이월 → 유료 코호트 3개월 → 판정), 태우는 통화 = 저자 시간 약 220h + 현금 약 1,100,000원(툴 540,000 **유도** / 사업자·세무 300,000 **임의** / 도메인·결제·소재 260,000 **임의**) + 마감 연속 26회의 감정 노동. 9개월 뒤에도 표본이 부족하면 결론 불가이며 P3 또는 중단으로 간다.

## 문제 정의 / 목표

목표는 구독자 수가 아니라 **9개월 안에 단위 경제 성립 여부를 실측으로 판정하는 것**이다. 성립 조건은 위 임계값 문장 하나이며, 나머지 계획은 그 문장을 측정 가능하게 만드는 도구다.

## 명시적 가정

- **저자가 9개월간 월 40시간(제작 20h + 성장 20h)을 지속 투입할 수 있다.** 틀리면 고정비 분모와 리스트 성장이 동시에 붕괴한다. 가장 싼 조기 검증: 무료 8회를 실제 일정으로 소화하며 회차별 실소요를 주 1회 기록. 폴백: 월 1회로 내려 고정비 660,000원·가격 19,000원 기준 N\*=30으로 재산출.
- 니치 모집단이 국내 최소 15,000명. 틀리면 리스트 1,200 자체가 불가능 → S3이 열리지 않고 P3/중단.
- 겸업·기밀 조항이 유료 발행을 금지하지 않는다. 틀리면 플랜 무효 → S0에서 문서 확인.
- 국내 카드 정기결제 + 세금계산서 발행 레일이 존재한다. 틀리면 결제 실패율이 m을 직접 깎는다.
- 지인 구독은 전환율을 과대 추정시킨다. 틀렸다면 태깅 비용만 낭비된다.

## 접근 및 단계

각 단계는 원장의 어느 변수를 확정하는지로 정렬한다(달력이 아니라 의존).

- **S0 전제 게이트** — 선행 없음. 겸업·기밀 조항, 사업자·부가세 유형, 결제 레일, 사내 사례 익명화 기준. 검증: 테스트 결제 1건 승인 + 세금계산서 1건 발행. 실패 시 중단. 확정: 수수료율·VAT.
- **S1 니치·가격 고정** — 선행 S0. 개인 29,000원 + 팀 5석 99,000원. 팀 좌석을 1일차에 두는 근거는 원장에서 나온다: 필요 가격이 개인 지출 임계를 넘으므로 회사 경비 결재 경로가 없으면 4.8%가 안 나온다. 검증: 팀 좌석 문의 ≥ 3건.
- **S2 무료 8회 + 타임로그** — 선행 S1, 공개 글 4편 병렬. 검증: 회차별 실소요 8건, 리스트 성장, 오픈율 4주 이동평균. 확정: 제작시간·오가닉 획득. **S1 복귀 조건**: 실측 제작시간 중앙값 13h 초과 시 S3으로 가지 않고 S1로 되돌아가 가격·빈도 재산출(13h는 **유도** — 그 지점에서 고정비 1,620,000원, N\*=73, 필요 전환율이 벤치마크 하단 5%를 넘는다).
- **S3 페이월 게이트** — 선행 S2 통과. 기본값 있는 게이트: 리스트 ≥ 1,200 **그리고** 오픈율 ≥ 40%면 개시, 미달 시 무료 4회 연장 후 재판정, 2회 연장 실패면 S4 조기 진입. 1,200은 **유도**(전환율 95% CI를 ±1.2pp로 좁혀 4.8%와 9%를 구분하는 최소 표본), 40%는 **수명 제한**(S2 실측 중앙값 교체).
- **S4 판정** — 선행 S3 + 유료 코호트 3개월. 실측 전환율·이탈률로 N\* 재계산해 실제 유료 수와 한 표에서 비교. 분기: 초과 → S5 / 60~99% → 가격 인상 또는 팀 좌석 전환 후 3개월 재관측(1회 한정) / 60% 미만 → P3 이행 또는 중단. 60%선 **임의**(재관측 시간 예산이 3개월뿐이라는 제약에서 잡음).
- **S5 유료 획득 실험(성립 시에만)** — 선행 S4 초과 판정. 실측 LTV/3을 CAC 상한으로 고정하고 30만원 스파이크. 검증: 실측 CAC ≤ 상한, 초과 시 즉시 중단·오가닉 복귀.

## 대안과 기각 사유

- **A1 원안(일반·9,900원·주 4회)** — 필요 전환율 8.5% > 벤치마크 상단 5%. 부활: 리스트 12개월 실측 8,000명 초과 또는 전환율 실측 6% 초과 시(가격 저항이 낮아 확장성이 크다).
- **A2 연간 결제 단독** — 수수료율 16.9%→13.3%로 원장상 유리하지만 기각. 이 플랜의 산출물은 이탈률 실측치이고 연납은 12개월간 이탈을 관측 불가로 만든다 — 마진을 사려고 측정 장치를 파는 거래다. 부활: S4에서 월 이탈률 3개월 실측 완료 후 연납 할인 15% 도입.
- **A3 유료 광고 선행 획득** — CPC 1,000~3,000원 × 랜딩 20% × 유료 4.8% → CAC 104,000~312,000원 vs 원안 상한 48,000원. 기각. 부활: P1 채택 후 실측 LTV 400,000원 초과 + 스파이크 CAC ≤ 147,000원(S5).
- **A4 무료+스폰서십(P3)** — 리스트 15,000명 필요로 현시점 기각. 부활: S4 철수 분기의 지정 기본값(스텁 원장은 위).

## 리스크 & 완화

- 법·규제: 겸업·기밀 조항 → S0 문서 확인, 위반 시 무효. 청약철회 → 환불 정책 명문화 + 원장 환불 라인 반영.
- 세무: 부가세·사업자 유형 오판 → S0 확정 전에는 유료 결제를 받지 않는다.
- 측정 오염: 지인 코호트가 전환율을 부풀림 → 최초 50명 별도 태깅, 전환율·이탈률 산출에서 제외.
- 번아웃: 26회 연속 마감 → 지연 2회 시 빈도 자동 인하(가격 동시 조정).
- 플랫폼 의존: 계정 정지·정산 지연 → 리스트 원본 주 1회 자체 백업.
- 경쟁·대체재: 무료 강자(기술 블로그·큐레이션) → S1 모집단 근거에 "무료로 이미 충족되는 부분" 명시.
- 개인정보: 처리방침 게시, 수집 항목을 이메일로 한정.
- 판정 전 중단: S4 없이 종료하면 "결론 불가"로 기록하고 성공/실패로 쓰지 않는다.

## "완료"의 판정 기준

1. (실측 가능) **9개월 차에 발행 26회 이상이 나갔고, 유료 코호트의 3개월 연속 이탈률(월초 유효 구독 대비 당월 해지)과 페이월 노출 대비 전환율이 지인 코호트 제외 기준으로 산출되어 있으며, 그 실측치를 대입한 N\*와 실제 유료 구독자 수를 한 표에서 대소 비교할 수 있다.** 두 수의 대소가 정해지지 않으면 미완이다.
2. 수명 제한 숫자 4종(제작시간, 이탈률, 오픈율, 오가닉 100명/편)이 실측치로 교체돼 있다. 단 S3이 열리지 않은 경우 이탈률은 "미측정"으로 기록하는 것으로 갈음한다 — 페이월이 없으면 원리상 측정 불가이므로 이 항목이 완료를 막지 않는다.
3. S4 분기 하나가 문서화된 기준으로 선택돼 있다. "일단 계속"은 선택지가 아니다.
4. 판정이 부정이어도 완료다 — 산출물은 흑자가 아니라 판정이다.

## 프레임 이탈 / 관성 회귀

- 가장 약한 절은 **S1**. "니치를 좁히면 전환율이 오른다"를 근거 없이 깔았다 — 모집단 15,000명은 가정에 올렸지만 니치별 전환율 상승폭에는 근거가 없다. 4.8%가 "하단에 겨우 걸린다"는 판정 전체가 이 미검증 전제에 얹혀 있다. 29,000원도 원장에서 역산한 값이고 시장 근거를 못 붙였다.
- 관성 회귀: S0→S5가 상승 계단으로 서 있다. S2에 S1 복귀 조건을 넣어 화살표 하나는 되돌렸지만 S3·S4에서 가격 가설로 돌아가는 경로는 없다 — S4 미달 분기는 "가격 인상" 한 방향뿐이고, 유료 코호트를 본 뒤 가격이 너무 높았다고 판명되는 흔한 경우가 빠졌다.
- 관행 선택: 월 이탈 5%가 LTV와 CAC 상한을 모두 결정하는데 벤치마크를 그대로 넣었다. 교체 전까지 A3 기각도 이 숫자에 의존한다.
- 내가 리뷰어라면 칠 곳: **부호 안정성 절의 두 벤치마크 밴드(2~5%, 5~10%)**. A1 기각과 P1 채택의 경계가 실측 대 실측이 아니라 벤치마크 대 벤치마크로 갈렸고, 대체 데이터는 S3 이후에야 생긴다 — 시작 결정이 가장 못 믿는 숫자 위에 서 있다.
- 리스크 절 8행 중 완화책 대부분이 "문서화·명시" 수준이어서 구조가 아니라 예의다. 원장에 실제로 개입하는 것은 측정 오염(지인 코호트 제외)과 번아웃(빈도 자동 인하) 두 행뿐이다.
