# "가끔, 특정 사용자에게만, 재현 불가" 버그 조사 플랜

- 추론 프레임: hypothesis-loop / 스타일: opus
- 한 줄 요약: 산출물을 수정이 아니라 **재현 레시피**로 고정하고, 계측 인공물을 0행에 둔 6행 가설 원장을 좌표축을 바꿔가며 관찰→갱신 루프로 돌린다.

## 프레임이 요구하는 시작점 — 사실 / 추측 분리 원장

| 항목 | 관찰된 사실 (출처 지정, 값은 S0에서 채움) | 추측 — 검증 전 사용 금지 |
|---|---|---|
| 빈도 | CS 티켓 유입 건수 (지원 채널) | 이 건수가 실제 발생률이다 → **H0 대상, 의심 표시** |
| 영향 범위 | 티켓 제출자의 계정 id 목록 | 제출자 집합 = 영향 집합, 즉 "특정 사용자에게만" |
| 시점 | 티켓·서버 로그 타임스탬프 (UTC 기록) | 불규칙·무작위하다 |
| 재현성 | 사내 재현 시도 실패 (시도 조건 미기록) | "재현 불가" — 조건이 기록되지 않은 실패는 재현 불가의 증거가 아니다 |
| 오류 지문 | 스택·로그 시그니처의 티켓 간 동일성 **미확인** | 하나의 버그다 (→ 가정 A4, 규칙 R4에서 매 라운드 재심) |

좌표계 회의: **"사용자"는 관찰이 아니라 좌표 선택이다.** sticky 라우팅·테넌트 단위 설정·기기 고정 환경은 인프라 원인을 사용자 모양의 군집으로 제조한다. 그래서 조사 단위를 `user`에서 `session × build-hash × route(노드·리전·카나리) × local-time`으로 바꾼다. 이 교체가 "영향 계정을 열어 뭐가 이상한지 본다"는 반사 단계를 죽였고, 그 자리를 S1의 축별 재클러스터가 맡는다. H4는 이 교체로 생긴 행이다.

## 문제 정의 / 목표

1차 산출물은 **재현 레시피**(제3자가 따라 할 수 있는 조건 문서), 2차는 승격된 원인 가설이다. 수정은 범위 밖이다 — 레시피가 있으면 수정은 평범한 작업이고, 레시피 없는 수정은 검증 불가한 추측 배포다.

## 명시적 가정 (각각 틀렸을 경우의 영향)

- **A1 (전체가 걸린 가정) — 티켓 없이도 로그만으로 영향 세션을 식별할 수 있다.** 틀리면 원장 전체가 티켓 표본에 종속되어 H0가 영구 미해결이고 어떤 기각 조건도 해석되지 않는다. 최저비용 조기 검증: 최근 로그에서 지문 후보 쿼리 1회(반일) → 티켓 미제출 영향 세션 ≥1건 발견 여부. 대체 경로: 0건이면 1라운드 목표를 "식별 계측 확보"로 축소하고 H1~H5 실험을 전부 보류한다.
- A2 조사 여유: CS 압력 하에서도 라운드 1회 동안 기저 동결(무개입)을 유지할 수 있다. 틀리면 이 진단 프레임은 사치이므로 완화 우선으로 전환하고 원장은 배경 탐지기로만 남긴다.
- A3 로그 보존기간이 발생 간격보다 길다. 틀리면 소급 마이닝이 불가해 전방 관찰 중심이 되고 라운드 길이가 보존기간에 갇힌다.
- A4 티켓들이 하나의 원인에서 나왔다. 틀리면 원장의 통계가 두 현상의 혼합이라 모든 기각 조건이 희석된다 → R4로 매 라운드 재심.
- A5 위 원장의 사실 칸에는 아직 **값이 없다**(출처만 지정). S0 이전에는 어떤 임계값도 계산되지 않으며, 값 없이 기각 조건을 대입하면 그 판정은 허구다.

## 가설 원장 — 기각/승격 조건 사전 등록 + 비용

승격 경로는 둘뿐이다(R2): 보기 전에 써둔 **홀드아웃 예측**의 적중, 또는 **유도–제거 재현**. 사후 해석으로는 어떤 행도 승격되지 않는다.

채점 규칙(두 사람이 독립적으로 같은 판정을 내리기 위한 최소 정의): 비영향군 = 같은 기간·같은 축의 무작위 세션 표본(n은 영향군과 동수). "구분되지 않음" = 해당 축 비율의 영향군/비영향군 비가 **2배 미만**. *배수 2는 임의 선언 값 — 대체 시점: S0에서 실측 발생률과 영향군 크기가 확정되면 표본 크기에서 재산출한다.* 라운드 중 이 값을 고치면 R3이 발동한다.

| # | 가설 | 기각 조건 (사전 등록) | 승격 조건 | 비용 |
|---|---|---|---|---|
| **H0** | 계측 인공물 — 티켓 수, 에러 그룹핑 병합/분할, 로그 샘플링율, 세션 단위로 붕괴한 사용자 식별자가 "가끔·특정 사용자"를 만들었다 | 서버 원본 로그 기반 발생률과 티켓 기반 발생률의 비가 2배 미만이고, 그룹핑·샘플링 감사에서 병합/누락 0 | 감사에서 계측 결함 1건 이상 발견 → 즉시 승격, **다른 모든 행의 관찰은 폐기 후 재수집** | 저 |
| H1 | 클라이언트 잔존 상태 — 스테일 번들, 구 스키마 로컬 저장소, 장기 미갱신 탭 | 영향 세션의 구 build-hash 비율이 비영향군과 구분되지 않음(위 채점 규칙) | 홀드아웃 예측("다음 라운드 영향 세션의 구 build-hash 비율이 비영향군의 2배 이상")을 보기 전 기록 → 적중 + 구 스키마 주입으로 유도, 저장소 초기화로 소멸 | 저 |
| H2 | 데이터 형상 — 대량·특수문자·NULL·1:N 초과·구 스키마 레코드에서 코드 경로가 갈린다 | 영향 계정 스냅샷을 격리 환경에 복제해 동일 조작 반복 시 0회 재현 | 스냅샷 복제로 재현 + 문제 레코드 제거 시 소멸 | 중 (익명화·승인) |
| H3 | 경합/순서 — 중복 요청·재시도·멀티탭·멀티디바이스 동시 세션 | 영향 이벤트의 동시 세션·중복 키 지문 비율이 비영향군과 구분되지 않음 | 인위적 동시 요청으로 유도 + 직렬화(락·멱등 키)로 소멸 | 중 |
| H4 | 인프라 파티션 — 특정 노드·샤드·리전·카나리로의 sticky 라우팅 | 영향 세션의 노드·리전·카나리 분포가 전체 트래픽 분포와 구분되지 않음 | 해당 파티션으로 강제 라우팅한 합성 세션에서 재현 + 파티션 이탈 시 소멸 | 저 |
| H5 | 환경 경계 — 브라우저 버전·확장·기업 프록시·시간대/로케일 경계(자정·DST·월말) | UA·로케일·UTC 오프셋 축에서 영향군 집중이 없음 | 동일 UA·로케일·오프셋 합성 환경에서 재현 + 축 하나만 바꿨을 때 소멸 | 저(축 재집계) / 고(실기기) |

## 접근 및 단계 — 의존 순서 (달력 아님)

- **S0 계측 감사 (H0).** 선행: 없음. 산출: H0 판정 문장 1개 + 실측 기저 발생률. 검증: 두 출처(서버 로그 / 티켓)의 발생률이 숫자로 적히고 비가 계산되어 있다. A5의 빈 칸과 채점 규칙의 배수를 채우는 단계다.
- **S1 좌표 재클러스터 (S0과 병렬, 저비용).** 선행: 로그 접근만. 동일 이벤트를 6축 — local time / 테넌트 / build-hash / UA·로케일 / 노드·리전·카나리 / 계정 연령·데이터량 — 으로 재집계한다. 검증: 축별 집중도 표가 존재하고 각 축 결과가 H1·H4·H5의 기각 조건에 대입된다. **결과는 H0 판정 전까지 `미해석` 태그로만 적재된다.**
- **S2 라운드 게이트 1.** 선행: S0. H0 승격 → S1 결과 폐기, 계측 수정 후 라운드 재시작. H0 기각 → 해석 개방.
- **S3 유도 재현.** 선행: S2 해석 개방 + 생존 가설. 생존 행마다 유도–제거 1회. 검증: 레시피 초안 + recipe-on/off 동일 n 대조.
- **S4 표적 계측.** 선행: S3에서 어떤 행도 승격 못 함. 규칙: **특정 가설의 기각/승격 조건이 요구하는 필드만** 추가한다. 검증: 필드마다 "어느 가설의 어느 조건을 판정하는가" 1줄. (가설 없는 계측 살포가 이 프레임의 실패 모드다.)
- **S5 라운드 종결 게이트.** 선행: S3 또는 S4. 출구는 루프 재진입 또는 소멸 기본값.

루프 규칙(반환 경로 — 사다리화 방지):

- R1 새 관찰이 H0를 흔들면 그 라운드의 모든 결론을 폐기하고 S0으로 복귀한다.
- R2 승격은 홀드아웃 예측 또는 유도–제거 재현만으로.
- R3 라운드 중 임계값을 수정하면 해당 가설을 **"보류"로 강등**하고 원장에 수정 이력 1줄을 남긴다.
- R4 매 라운드 단일 현상 전제 재심: 지문이 2군 이상으로 갈리면 원장을 군별로 복제해 따로 돌린다.
- R5 기저 동결: 라운드 동안 관련 배포·플래그·설정 변경 금지. 불가피한 변경은 오염 항목으로 기록하고 그 라운드 표본을 분리한다.

소멸 / 판정 불가 기본값: 3라운드 또는 타임박스 소진 후 전 행이 기각·보류면 **"판정 불가"를 정식 결론으로 채택**하고 (a) 원장을 배경 탐지기(지문 쿼리 + 알림)로 남기고 (b) 영향 사용자에게는 회복 조치만 적용하고 (c) A4를 폐기해 군별 재원장을 만든다. *라운드 수 3은 임의 선언 값 — 대체 시점: S0의 실측 발생률로 1라운드 필요 관찰기간이 계산되면 "총 관찰기간 ≤ 로그 보존기간" 제약으로 재산출한다.*

## 대안과 기각 사유

- **즉시 방어적 수정 배포**(전역 예외 처리·재시도·상태 초기화): 기각 — 증상의 매체를 없애 재현 레시피가 영구 불가가 되고 원장이 미제로 봉인된다. 부활 조건: 데이터 손실·금전 이동 같은 회복 불가 피해가 관측되면 즉시 채택(원장은 유지, "완화가 관찰을 오염시켰음"을 기록).
- **전면 계측**: 기각 — 비용·프라이버시, 그리고 가설 없는 계측이 곧 실패 모드. 부활 조건: 3라운드 소진 후 어떤 축에서도 집중이 검출되지 않으면 병목은 표본이므로 지정한 1~2축에 한해 확대한다.
- **사용자 원격 세션 우선**: 기각 — 비용 원장에서 최상위(사용자 시간·일정 조율)인데 간헐성 탓에 성공률이 낮아, 비용 필드가 이 대안을 로그 마이닝 아래로 내렸다. 부활 조건: H5만 생존하면 최저비용 결정 실험으로 승격.

## 리스크 & 완화

- 프라이버시/규제: H2의 스냅샷 복제는 개인정보 처리다 → 익명화·접근 승인·보존 만료를 S3 선행조건으로 못박는다.
- 서드파티·통제 불가 노드(CDN·결제·확장): 라벨이 아니라 처방으로 — 값 통제 대신 관측 해상도만 확보하고, 승격 조건을 "공급자 상태·버전과의 시간 상관"으로 완화하며, 판정 불가 기본값의 대상으로 미리 지정한다.
- 조기 수렴 압력(CS·영업): R2·R5가 구조 방어. 압력에 의한 개입은 오염 항목으로 기록한다.
- 조사 피로·미제 장기화: 타임박스 + 소멸 기본값이 종료를 선언한다.
- 관찰이 개입이 되는 문제: 사용자 접촉(설문·원격) 코호트와 조사 중 개별 우회 조치를 받은 세션은 표본에서 제외 표시한다.

## "완료"의 판정 기준

1. **(실측 가능한 주 판정문)** 제3자가 레시피 문서만 읽고 깨끗한 환경에서 실행해 recipe-on 조건 n=10에서 동일 오류 지문(같은 스택 시그니처·같은 로그 필드)을 8회 이상 재현하고, recipe-off 대조 n=10에서 0회 → 레시피 확정. *8/10은 임의 선언 값 — 대체 시점: S0에서 기저 발생률이 확정되면 "recipe-on 발생률 ≥ 기저율 × 10"으로 교체한다. 배수 10도 근거 없는 자리수이며, n=10 이항 대조에서 유의미한 최소 격차를 계산해 확정한다(기저율 미지 상태에서는 그 계산 자체가 불가했다).*
2. 원장 6행 전부가 기각·승격·보류 중 하나로 판정되고, 보류 행마다 다음 라운드 조건이 1줄 적혀 있다.
3. 탐지 경로 생존 확인: 합성 결함을 주입해 지문 쿼리와 알림이 실제로 발화함을 확인한다. "이후 사고 0건"은 계측 사망으로도 만족되므로 이 프로브가 있을 때만 0이 의미를 가진다. (safety-net 프레임의 "미발화 재해석" 부품 차용 — 출처 기록.)
4. 판정 불가로 종결한 경우: 무엇을 측정하지 않았는지(어떤 축·어떤 가설이 비용으로 배제됐는지)가 문서에 남는다.

## 프레임 이탈 / 관성 회귀

- **채점 불가능한 기각 열을 먼저 썼다(§가설 원장):** H1·H3·H4의 기각 조건을 "비영향군과 구분되지 않음"으로만 적어 두 사람이 같은 판정을 낼 수 없는 상태로 원장을 완성했다가, 뒤늦게 비교 기준·배수 2 규칙을 표 위에 붙였다. 사전 등록은 채점 규칙이 있을 때만 사전 등록이며, 그 규칙 없이 원장을 쓴 것이 이 문서에서 가장 컸던 회귀다.
- **빈 사실 원장(§시작점 표):** 사실 칸에 값이 없고 출처만 있다. 실제 데이터가 없으니 정직한 상태지만, 사실 절반이 빈 채로 원장 6행과 임계값을 먼저 쓴 것은 프레임이 요구한 순서를 뒤집은 것이다(A5로 표시).
- **단계 번호의 사다리(§접근 및 단계):** S0∥S1 병렬과 R1 반환이 있는데 S0→S1→S3→S4의 오름 번호로 적혔고, 규칙을 붙여도 실행자는 번호를 따라갈 것이다.
- **숫자에서 관행 회귀(§완료 1):** ×10의 근거는 끝까지 만들지 못했다.
- **H5 비용 미판정(원장 H5행):** 비용을 "고"로만 적고 실기기 조합을 몇 개 확보할지 정하지 않아 이 행에서는 비용 원장이 우선순위를 못 낸다.
- **무난한 출구 의심(소멸 기본값):** "판정 불가 + 배경 탐지기"는 프레임이 요구한 부품이지만 조직이 가장 삼키기 쉬운 결론이기도 하다. 부품 충족인지 안전한 착지인지 스스로 구분되지 않는다.
- 커버리지 스윕 회수 범주: 법/규제(개인정보) → 리스크 1행 + S3 선행조건, 서드파티 통제 불가 → 리스크 2행. 아직 행이 없는 범주: 조사 인건비 예산, 모바일·오프라인 클라이언트의 버전 스큐(H1·H5에 흡수된다고 판단했으나 명시 행은 없다).
- 리뷰어라면 §완료 1을 칠 것이다: 제3자 재현을 요구하면서 그 제3자를 누가 확보하는지, 그 환경이 H4를 재현할 권한을 갖는지 적혀 있지 않다.
