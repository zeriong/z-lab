# 개발자 유튜브 채널 런칭 — 12개월 후 "정지"에서 역구성한 플랜
- 추론 프레임: premortem
- 한 줄 요약: 채널은 소재나 시간이 없어서 죽지 않는다 — 편당 비용이 단조 상승하고 정지를 선언할 사람이 없어서 죽는다. 그 두 사인만 구조로 막는다.

## 프레임이 요구하는 시작점 — 부검 보고서 (사망은 기정사실)

반사적으로 쓰고 싶은 것은 "주 1회 업로드 + 12주 콘텐츠 캘린더"다. 프레임은 그 캘린더가 **어떻게 죽었는지**부터 쓰게 한다. 아래 수치(조회수·제작시간·간격)는 인과 사슬을 특정하기 위한 서술 장치이며 예측치가 아니다.

**사망 기록.** 마지막 업로드는 9번째 영상. 종료 선언 없음, 채널 삭제 없음, 커뮤니티 탭에 "요즘 바빠서" 한 줄. 사망 시점을 특정할 수 없다 — **선언자도 시점도 없다는 사실 자체가 1차 사인이다.**

- **M1–M2.** 1편 210회, 2편 90회. 결정적 전환이 여기서 일어난다 — 저조한 반응은 게으름을 만들지 않았다. **과잉투자**를 만들었다. "다음 편은 더 잘 만들어야 한다" → 편집 3시간이 9시간이 된다.
- **M3.** 릴리즈 스프린트로 주말 2회 소진. 간격 12일 → 26일. 간격이 벌어지자 "오랜만이니 큰 걸 올려야 한다" → 4부작 기획 → 1편도 못 낸다. 기획이 **부채**가 된다.
- **M4–M6.** 본인은 원인을 "소재 고갈"로 보고한다. 실제로는 소재가 없어진 게 아니라 **채택 기준이 올라갔다** — 조회수가 날 만한 주제만 소재로 인정된다. 여기에 "업무에서 배운 건 사내 맥락이라 못 쓴다"는 판단이 겹쳐 풀이 좁아진다.
- **M7.** 8편이 1,400회, 첫 국소 성공. 그 편의 제작시간은 21시간이었다. **성공이 기준선을 다시 올려 사인에 기여한다.**
- **M8–M12.** 9편 이후 정지. 종료 선언이 없으니 복귀 부담만 매달 누적되고, 접지도 넘어가지도 못한다.

**사인의 연쇄.** 저조한 초기 반응 → 품질 기준 인플레이션 → 편당 비용 상승 → 본업 충돌 시 우선순위 상실 → 간격 확대 → 복귀 부담 상승 → 기획 규모 확대 → 미완성 → "소재 고갈"로 오인 → 선언 없는 정지.

**병소는 소재도 시간도 아니다. 편당 비용의 단조 증가와 정지 선언의 부재다.**

## 커버리지 스윕 (서사와 독립된 범주표)

범주 목록은 서사를 쓰기 전에 고정한 표준 목록(법·규정/돈/보안/조직/건강/사용자/검증)에 도메인 1개(플랫폼·저작권)를 더한 것이다. **통과 기준: 서사에 없던 사인 ≥1건** — 네 범주가 서사에 0회 등장했다(통과).

| 범주 | 서사 | 서사에 없던 사인 경로 | 착지 |
|---|---|---|---|
| 법·규정 | 없음 | 겸업 조항 위반 → **강제 종료** | 0단계 ①, 가정 1 |
| 플랫폼·저작권 | 없음 | BGM·게임화면·코드 라이선스, TOS 기반 채널 정지 | 0단계 ④ |
| 보안 | 없음 | 화면 녹화에 API 키·사내 URL·고객 데이터 노출 → 1회 사고로 사망 | 0단계 ③, 리스크 |
| 돈 | 없음 | 툴 구독 누적, 수익 발생 시 세무 신고 | 리스크 2행 |
| 조직 | 부분 | 동료·상사의 인지, 정보 유출 의심 | 0단계 ②(사전 통보) |
| 건강 | 부분 | 주말 전면 소진 → 수면 붕괴가 비용 상승을 가속 | 리스크(제작 블록 상한) |
| 사용자 | 부분 | 대상 오설정(입문자 vs 실무자) → 피드백 신호 오독 | 5단계 |
| 검증 | 없음 | 플랜 자체를 재판정하는 장치가 없어 감으로 규칙을 흔든다 | 6단계 재검토 게이트 |

## 문제 정의 / 목표

12개월 후 채널이 **판정 가능한 상태**로 있게 한다: 편당 비용이 초기 수준을 유지한 채 발행이 계속되거나, 명시적 종료 공지로 끝난다. 조회수·구독자는 목표가 아니다 — 통제 불가 노드이고, 목표에 넣는 순간 첫 번째 사인을 플랜에 내장한다.

## 명시적 가정

1. **고용계약·사규가 영상 공개와 겸업을 금지하지 않는다.** 틀리면 플랜 전체 무효. 가장 싼 조기 검증: 0단계에서 계약서·사규 전문 검색 + HR 1문 질의(1일). 폴백: 사내 맥락 0인 순수 학습 소재 축소판, 또는 사내 기술 블로그로 매체 전환.
2. 주당 확보 가능한 제작 시간 4시간. 틀리면(2시간) 플랜이 무효가 아니라 포맷이 자동 하강한다(2단계).
3. 편당 비용은 방치하면 상승한다(부검의 핵심 관찰). 틀리면 1단계 상한은 불필요한 관료주의다. 검증: 3편의 제작시간 로그.
4. 소재는 고갈되지 않고 기준이 상승한다. 틀리면 은행이 실제로 비므로 주제 축을 바꿔야 한다.

## 접근 및 단계

**0단계 — 합법성·보안 게이트** (선행: 없음 / 차단: 강제 종료·보안 사고 — 스윕 발견분)
① 계약서 겸업 조항 원문 인용 1건 ② 상사 통보 기록 ③ 녹화 전용 OS 계정(사내 VPN·북마크·비밀번호 관리자 없음) ④ 사용 예정 BGM·폰트·게임 화면 라이선스 확인.
**게이트 기본값 = 진행 불가.** 4항목 전부 통과 없이는 촬영하지 않는다.

**1단계 — 편당 비용 상한** (선행: 없음, 0단계와 병렬 / 차단: 품질 인플레이션)
1편 총 제작시간 ≤ **4시간**(촬영+편집+썸네일+업로드). *파생: 가정 2의 주당 4시간 × 1주.* 상한 도달 시 **그 시점 상태로 발행**한다(연기 아님). 검증: 편당 4구간 스톱워치 로그(본인, 휴대폰 타이머, 스프레드시트 1장). **3편**(*임의값 — 우연과 경향을 가르는 최소치. 6단계 게이트에서 실측 분산으로 대체*) 연속 초과 시 상한을 올리지 않고 포맷을 내린다.

**2단계 — 포맷 하강 계단** (선행: 1단계 / 차단: 간격 확대 → 기획 부채)
A) 대본+컷편집 4시간 → B) 화면녹화 원테이크·자막 없음 **90분** → C) 5분 이하 "오늘 배운 것" 무편집 **30분**. *B·C는 A 상한에서 역산한 배분치이며 실측 3편으로 대체.*
**규칙: 주기를 못 지키면 주기를 늘리지 않고 포맷을 내린다.** 하강은 고장이 아니라 정상 동작이다.
검증: 발행 로그에 등급이 기록되고 C등급 ≥**2회** 존재(*임의값 — 하강 경로 작동의 최소 증거. 0회면 계단은 장식이다*).

**3단계 — 소재 은행과 채택 기준** (선행: 0단계의 공개 가능 범위 / 차단: "소재 고갈" 오인)
채택 기준은 조회수 기대가 아니다: ① 지난 2주 안에 실제로 겪었다 ② 0단계 보안·라이선스 통과 ③ C포맷으로 30분 안에 말할 수 있다.
은행 하한 **8개**(*임의값 — "2개월치"라는 관습에서 왔고 파생이 아니다. 3편 발행 후 실측 소진율로 대체*). 미달 시 다음 발행은 자동 C포맷.

**4단계 — 본업 충돌 프로토콜** (선행: 2단계 / 차단: 우선순위 상실)
스프린트·온콜 주간을 캘린더에서 사전 식별 → 자동 C포맷, 또는 **사전 선언된 휴재**(커뮤니티 탭 1줄 공지 필수). 침묵은 금지된다. 검증: 무공지 결번 0회.

**5단계 — 반응 오독 방지** (선행: 3편 이상 발행 / 차단: 저조한 초기 반응의 심리)
조정 신호는 둘만: ① 제작시간 로그 ② 시청 지속률. **1–6편의 조회수는 어떤 값이어도 포맷·주기·대상을 바꾸지 않는다**(*6편은 임의값 — 6개월 재검토 게이트에서 지속률 실측으로 대체*).

**6단계 — 착지 규칙과 재검토 게이트** (선행: 1–5 / 차단: 선언 없는 정지)
- 연속 **8주** 발행 0회 → 그 시점에 **종료 공지를 발행한다**(기본값 = 종료 선언, 침묵 아님). 3문장: 왜 멈추는가 / 재개 조건 / 기존 영상 유지 여부. *8주는 임의값이고 근거는 관습이다 — 6개월 재검토에서 실제 최장 공백으로 대체.*
- 재개는 종료 공지를 취소하는 형태로만. 조용한 부활 금지, 재개 1편은 C포맷 고정.
- **6개월 재검토 게이트**(스윕의 검증 범주 착지): 제작시간 로그로 상한·주기·포맷 시간·은행 하한을 한 번에 재판정. 상한 변경은 이 자리에서만 가능하다.

## 대안과 기각 사유

1. **주 1회 고정 캘린더 + 12주 기획표.** 기각: 사인은 주기 미준수가 아니라 편당 비용 상승이었다. 캘린더는 사인을 못 건드리고 결번마다 죄책감만 더한다. **부활:** 제작시간 로그 8편 평균이 상한 이하로 안정되면 얹는다.
2. **매체를 블로그로 변경.** 기각: 유튜브가 주어진 조건. **부활:** 가정 1이 깨질 때의 지정 폴백.
3. **공동 진행자.** 기각: 상대 일정이 새 임계 경로가 되고 본업 충돌이 2인분으로 확대된다. **부활:** C포맷 자력 발행 6회 이후.
4. **초기 수익화(멤버십·스폰서).** 기각: 수익이 기준선을 올려 품질 인플레이션을 가속한다 — M7에서 성공이 사인에 기여한 것과 같은 기제다. **부활:** 편당 비용이 상한 내에서 12편 유지.

## 리스크 & 완화

| 리스크 | 완화 |
|---|---|
| 강제 종료(겸업·기밀) | 0단계 게이트, 폴백 = 사내 맥락 0 소재판 |
| 보안 사고 | 전용 OS 계정 + 발행 전 화면 1회 스크럽. 사고 시 즉시 비공개(공개 유지 판단 금지) |
| 저작권·수익화 제한 | 라이선스 확인된 BGM 목록만 사용. 수익이 발생하면 세무 신고 여부를 먼저 확인 |
| 수면·건강 | 제작 블록 상한: 평일 저녁 2 + 주말 1. 주말 전면 소진 금지 |
| 비용 누적 | 툴 구독 월 **3만원** 상한(*임의값. 초과 시 무료 도구 회귀*) |
| 규칙 자체가 짐이 됨 | 운영 장치는 로그 1개 + 게이트 2개로 제한. 로그가 2주 연속 미기록이면 **로그를 줄인다** |
| 조회수 상승 후 상한을 올림 | 상한 변경은 6개월 재검토 게이트에서만 |

## "완료"의 판정 기준

1. **동일 포맷 등급 안에서 비용이 상승하지 않았다: A포맷 마지막 3편의 평균 제작시간 ≤ A포맷 첫 3편 평균의 1.2배.** 측정: 편당 4구간 스톱워치 합, 본인, 스프레드시트 1장(*1.2는 임의값 — 6개월 재검토에서 실측 편차로 대체*). 포맷 계단은 이 문장을 자동 만족시키지 못한다(등급 내 비교이므로 하강으로 값을 낮출 수 없다). A포맷이 6편 미만이면 B포맷으로 동일 비교하고, 두 등급 모두 6편 미만이면 **판정 불가로 기록한다**(통과로 셈하지 않는다).
2. 12개월간 **무공지 결번(2주 이상 침묵 + 공지 없음) = 0회.**
3. 12개월 시점의 상태가 둘 중 하나로 판정된다: (a) 최근 8주 내 발행 ≥1건, (b) 종료 공지 게시됨. **"애매하게 멈춰 있음"은 실패로 판정한다.**
4. C등급 발행 ≥2회 — 하강 경로가 작동한 증거.
5. 조회수·구독자는 판정에 넣지 않는다.

## 프레임 이탈 / 관성 회귀

- **3단계의 8개, 6단계의 8주는 근거가 관습이다.** 임의값 태그와 대체 시점은 붙였지만 파생이 아니고, 8주는 판정 기준 2의 "2주"와 같은 축에서 나오지 않았다.
- **5단계는 구조가 아니라 예의다.** Studio를 열면 조회수가 먼저 보인다. 지속률만 적는 로그 칸을 넣어봤지만 조회수를 안 보게 만드는 장치는 못 만들었다. 리뷰어라면 이 섹션을 먼저 친다.
- **사용자 범주가 가장 얇다.** 스윕에서 잡아 5단계 신호 규칙 한 줄로만 착지했고, 대상 오설정이 사인 연쇄의 **어디에 붙는지**는 쓰지 못했다.
- **대안 4의 기각 근거는 허구다.** M7의 "21시간짜리 1,400회"는 내가 쓴 서술 장치이고, 그것에서 도출한 기각이다.
- **두 상한의 충돌을 계산하지 않았다.** 월 3만원 상한을 지켜 무료 도구로 회귀하면 편집 시간이 늘어 1단계의 4시간 상한을 압박한다. 검토 없이 두 상한을 나란히 뒀다.
