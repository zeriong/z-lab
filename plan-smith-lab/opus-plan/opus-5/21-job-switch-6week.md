# 5년차 개발자 이직 준비 6주 — 3트랙 병렬 설계
- 추론 프레임: option-parallel
- 한 줄 요약: 대기업 집중·스타트업 집중·해외 원격을 같은 골격으로 동등하게 설계하고, 선택은 W3 게이트에서 독자가 프로브 판독 수치로 내린다.

## 프레임이 요구하는 시작점 — 단일 추천 없음

이 과제를 보자마자 떠오른 반사적 습관은 "5년차면 대기업이 정답, 나머지는 대안으로 짧게 붙이기"였다. 프레임이 금지하는 것이 정확히 그것이라, 세 트랙은 **동일 행 골격**으로만 서술하고 추천 문장을 쓰지 않는다.

**생존가능성 사전점검** — 미달 트랙은 삭제하고 남은 것으로 다시 시작한다.

| 트랙 | 최소 요건 | 미달 시 |
|---|---|---|
| A 대기업 집중 | 주 12h + 공고 실재 + 결론까지 8주 대기 가능 | 삭제 — 6주 내 오퍼가 요구조건이면 산술적으로 불가 |
| B 스타트업 집중 | 과제 8h 연속 확보 + 최근 2년 내 직접 만든 산출물 1건 | 삭제 — 과제전형을 통과할 표본이 없음 |
| C 해외 원격 | 영문 비동기 쓰기 실물 이력 + 22–24시 주 2회 가용 + 고용형태(EOR/계약자) 성립 + 경업금지 저촉 없음 | 삭제 — 계약이 성립하지 않으면 전형 통과도 무의미 |

**산술이 선택을 하나로 붕괴시키면 선택 문제가 아니라 제약 문제다.** "6주 내 서명된 오퍼"가 요구조건이면 A(리드타임 8–12주)와 C(4–10주)가 탈락해 B만 남고, 그때는 이 플랜을 버리고 제약 우선 문서를 써야 한다. 이 플랜은 6주 목표를 오퍼가 아니라 **"한 트랙 파이프라인의 실가동"**으로 정의해 세 트랙을 살려둔다.

## 문제 정의 / 목표

6주에 얻을 것: ① 세 트랙 중 하나를 수치 근거로 선택, ② 그 트랙에서 **타인이 만든 응답** 확보, ③ 어느 트랙에서도 버려지지 않는 공통 자산. 얻지 못할 것: 오퍼, 연봉 협상 결과, 수락 판단.

## 명시적 가정

- **재직 중이고 6주간 소득이 유지된다.** 틀리면 병렬 3트랙이 사치가 되어 플랜 전체가 무효 — 최단 리드타임 단일 트랙으로 축소한다. 가장 싼 조기 검증: W1에 팀 로드맵·평가 일정·조직 개편 신호 확인(1h).
- 주 가용 12h [수명: W1 타임로그 실측으로 대체]. 틀리면 프로브 3종을 2주로 늘리고 게이트를 W4로 미룬다(전환 캡은 유지).
- 리드타임 A 8–12주 / B 2–4주 / C 4–10주 [수명: W1에 실제 공고·현직자 확인으로 대체]. 틀리면 완료 기준의 응답 3건이 트랙별로 비대칭해지고 W10 재판정을 앞당긴다.
- 프로브를 채점·응답해줄 제3자(스터디·문제은행·공개 스레드)를 구할 수 있다. 틀리면 자기 채점이 되어 프로브가 연습으로 퇴화하므로, 판독을 에너지 항목만으로 제한한다.

## 트레이드오프 매트릭스 (동일 행)

| 행 | A 대기업 | B 스타트업 | C 해외 원격 |
|---|---|---|---|
| 관문 | 서류→코테→기술→임원 | 서류→과제→기술→대표 | 스크리닝→라이브코딩→설계→컬처 |
| 6주 종착 | 서류 통과 + 1차 기술면접 1건 | 과제 제출 + 최종 라운드 1건 | 스크리닝 + 1차 기술 라운드 1건 |
| 주 12h 배분 | 알고리즘 6 / CS 4 / 서류 2 | 과제 8 / 제품 서술 2 / 서류 2 | 영문 쓰기 4 / 설계 4 / 야간 모의 4 |
| 실패 신호 | 코테 2연속 미통과 + 3주 무응답 | 과제 2건 연속 무피드백 탈락 | 스크리닝 3연속 무응답 |
| 되돌아오는 비용 | 낮음 — 알고리즘·CS를 C에서 재사용 | 중간 — 과제물을 A 서류에 부분 재사용 | 높음 — 영문 자산은 국내에서 무가치 |
| 미측정 | 연봉 밴드, 조직 적합성 | 지분 가치, 런웨이 | 세무·거주지 규정 |

세 트랙의 6주 종착 상태는 **깊이가 달라 통약되지 않는다.** 그래서 완료 판정을 "같은 단계 도달"이 아니라 "타인이 보낸 응답 건수"로 통일한다.

## 프로브 — 측정 도구 동봉 (W2, 3개 병렬)

내성 질문("나는 어디가 맞을까")은 자기상에 오염되므로 쓰지 않는다. 각 프로브는 그 트랙의 **데스존**을 표본에 포함한다.

- **A**: 서로 다른 날 2회, 각 90분 타이머, 중난도 2문제. 채점은 제3자가 하고 결과는 이유 없이 "통과/탈락" 한 단어로만 받는다. 2회차는 1회차 결과와 무관하게 실행한다. (데스존 = 반복 + 무설명 탈락 / 90분 [근거: 코딩테스트 관행 슬롯])
- **B**: 실제 공고 과제 1건을 주말 8h 연속 수행하고, 미완 상태여도 마감 시각에 제출한다. 제출은 채용 메일 또는 공개 리포지토리로 하고, 피드백은 제3자에게 요청한다. (데스존 = 무보수 완주 + 미완 노출 / 8h [근거: 공고 명시 관행])
- **C**: 영문 설계 리뷰 답글 3건을 각 30분 제한으로, 타인 응답이 달리는 공개 스레드에 쓴다. 22:00–24:00 모의 인터뷰 2회를 서로 다른 날, 상대를 제3자로 구해 진행한다. (데스존 = 시차 + 영문 즉시성 / 30분 [근거: 파생 — 재직 중 확보 가능한 최소 단위])

**프로브 시간 개정 규칙**: W1의 공고 확인 값이 관행값과 다르면 프로브 시간은 공고값을 따른다.

**판독 규칙(다음날 오전, 성과 회고 전에 기록)**: ① 그 트랙 작업 재착수까지 걸린 시간(분), ② "오늘 한 번 더 할 수 있나" 즉답 예/아니오. 실력 점수는 판독에 쓰지 않는다 — 실력은 6주에 바뀌지만 에너지 반응은 6개월을 결정한다. 프로브 도중이 아니라 끝난 다음 읽는다.

## 공통 코어와 유예 구간

W1–W2 산출물은 어느 트랙에서도 버려지지 않는다: ① 사실 대장(프로젝트 5건 × 기간·규모 수치·본인 결정 3개·실패 1개), ② 대표 프로젝트 1건의 설계 결정 서술(국문 1,200자 — 세 트랙 인터뷰 답변의 원본), ③ 레퍼런스 2명 사전 동의(현직 팀원 제외). **공통 코어가 아닌 것**: 알고리즘 그라인딩, 과제 산출물, 영문 이력서·답글 로그 — 전환 시 버려진다. 따라서 **선택을 미룰 수 있는 한계는 공통 코어가 끝나는 W2 말**이다.

## 스위치 데드라인·비용·기본값

- G1 = W3 금: 프로브 판독으로 1트랙 확정. G2 = W4 금: 마지막 전환 기회. **전환 캡 1회** [근거: 파생 — 최단 리드타임(B) 2주이므로 W4 이후 전환은 6주 내 외부 응답 확보 불가].
- 전환 비용: W3 = 프로브 시간 소실(≈10h). W4 = 준비 1주 소실(≈12h) + 제출한 지원 철회 불가. W5 이후 = 6주 내 결론 포기.
- **기본값 규칙(계산보다 먼저 고정)**: 판독이 갈리지 않으면 **되돌아오는 비용이 가장 낮은 트랙**을 택한다. 매트릭스 해당 행의 세 값으로 계산하면 기본값은 A다. 그 세 값은 실측이 아닌 추정이며, A가 관습적 정답과 겹치는 것은 우연이다 — 기본값은 선호가 아니라 판정 불가 시에만 발화하는 규칙이다.

## 접근 및 단계 (의존 순서 — 주차는 의존의 투영)

1. **공통 코어 3종** (선행 없음). 검증: 수치 없는 사실 항목 0개, 레퍼런스 2명 서면 동의. → W1–W2
2. **프로브 3개** (1을 소비, 셋은 서로 독립·병렬). 검증: 판독 기록 3건, 성과 점수 칸 공란. → W2
3. **G1 판정** (2를 소비). 검증: 판정문에 판독 수치 인용. *산출물 수가 3에서 1로 줄어든다 — 정상이다.* → W3
4. **선택 트랙 파이프라인 가동** (3을 소비). 검증: 제출 ≥3건, 각 건 날짜. → W4
5. **응답 처리 + G2** (4의 외부 응답을 소비 — 속도는 내 통제 밖, 진행이 아니라 대기 구간). 검증: 응답별 다음 행동 24h 내 기록. → W5
6. **종결 판정** (1·5를 소비). 검증: 완료 기준 전 항목 대조. → W6

## 대안과 기각 사유

- **단일 트랙 몰입(대기업만)**: 리드타임 8–12주라 6주 안에 정보 이득이 없다. 부활 조건: 시작 시점에 이미 서류 통과 상태면 병렬은 낭비이므로 즉시 단일.
- **6주 전 구간 3트랙 병렬**: 12h를 3분할하면 각 트랙이 임계량 미달이고 프로브가 실전으로 오인된다. 부활 조건: 주 가용 30h 이상(퇴사·휴직).
- **프로브 없이 성향 문답으로 선택**: 자기상 오염. 부활 조건: 최근 6개월 내 세 트랙 전형을 모두 겪었다면 그 기록이 프로브를 대체한다.

| 리스크 | 완화 |
|---|---|
| 트랙 쇼핑·영구 유예 | G1/G2 하드 게이트 + 전환 캡 1회 + 기본값 규칙 |
| 프로브가 신기함만 측정 | 데스존 강제(반복·완주·야간) + 다음날 판독 |
| 현직 노출 | 레퍼런스는 전 직장에서만, 지원 이력은 개인 기기 |

| 금전 타이밍(스톡·퇴직금·연차) | W1에 정산 시점 표 작성, 퇴사일 후보를 그 표에서 고른다 |
| 건강·수면(C 야간) | 야간 프로브 다음날 오전 일정 금지, 주 2회 상한 |

## "완료"의 판정 기준

1. **W6 종료 시점, 선택 트랙 로그에 타인이 보낸 서면 응답이 3건 이상 있다** — 서류 결과·과제 피드백·인터뷰 일정 확정 중 무엇이든, 각 건에 날짜와 발신 주체 기록. 발신자가 타인이므로 내 노력으로 자동 충족되지 않는다. [근거: 파생 — 최소 파이프라인이 지원 응답·중간 전형·결과 통보 3회의 외부 접점을 갖는다. 지원 건수로 세지 않는 이유: 지원은 혼자 만들 수 있다]
2. 프로브 판독 기록 3건에 재착수 시간(분)과 즉답 예/아니오가 있고 성과 점수 칸이 비어 있다.
3. G1 판정문이 판독 수치를 인용한다. "느낌"만 적혀 있으면 미달.
4. 등가성: 매트릭스 3열의 모든 행이 채워지고, 프로브 산문 3블록의 최장/최단 단어 비 ≤ 1.15 [임의 선언 — 첫 작성 후 실제 편차로 대체].
5. 1항 미달 시 결론 문장은 "선택 트랙의 리드타임이 6주보다 길다"이며, 준비 실패로 쓰지 않는다.

## 프레임 이탈 & 관성 회귀

- 기본값이 관습적 정답(A)에 착지했다. 규칙을 계산 앞에 고정하고 "되돌아오는 비용" 행의 세 값을 모두 보이게 썼지만 **그 값들이 내 추정**이다. 문서에서 가장 약한 지점 — 리뷰어라면 여기부터 공격한다.
- 단계 5는 대기 구간인데 단계 목록에서 4→5→6이 상승처럼 읽힌다. 단계 3의 산출물 감소 명시와 5의 "대기 구간" 표기 외에는 이 관성을 못 깼다.
- 사전점검에 무효화 조건을 올린 것은 C(고용형태·경업금지)뿐이다. A의 연봉 밴드와 B의 지분 가치·런웨이는 매트릭스 "미측정" 칸에만 있고 어떤 게이트에도 걸리지 않는다 — 세 트랙의 탈락 조건이 실제로는 비대칭하다.
