# 협동 보드게임 (2~4인 / 60분) — 실패 봉쇄로 짜는 규칙 골격

- 추론 프레임: failure-first
- 한 줄 요약: "재미없어지는 상태" 12종을 심각도 척도로 정렬하고, 상위 실패를 **구조적으로 발생 불가능하게 만드는 규칙만** 채택한다(에티켓은 등급 0으로 표시하고 버린다).

## 프레임이 요구하는 시작점 — 실패 목록과 심각도 척도

**척도 선언(채점 전 고정):** 심각도 = `재플레이 살해력`(1~3: 이 실패가 죽이는 세션 수 — 1회 / 다음 몇 판 / 이 그룹 영구) × `자력 회복 불가능성`(1~3: 세션 중 규칙 없이 되돌릴 수 있는가 — 쉽게 / 사회적 비용을 치르면 / 불가).

| # | 실패 상태 | 점수 |
|---|---|---|
| F1 | 쿼터백 — 알파 1인이 전원의 최적수를 계산해 지시 | 3×3=**9** |
| F3 | 비난 귀속 — 패배 원인이 특정 1인으로 지목됨 | 3×3=**9** |
| F4 | 해결됨 — 3판 후 정석 오프닝 발견, 긴장 소멸 | 3×3=**9** |
| F2 | 킹메이킹 — 사실상 무관해진 1인(자원 소진·개인 안전)이 판을 결정 | 2×3=6 |
| F5 | 시간 초과 — 60분 예산이 90분이 됨 | 2×3=6 |
| F6 | 죽은 게임 계속 진행 — 15분에 결정된 패배를 60분까지 소화 | 2×3=6 |
| F8 | 인원 스케일 붕괴 — 4인에서 1인당 결정 지분 무의미 | 3×2=6 |
| F9 | 무작위 무력감 — 옳게 계획했는데 주사위로 패배 | 2×3=6 |
| F12 | 색약·기호 미분화 — 해당 플레이어가 보드 상태를 판독 못 함 | 2×3=6 |
| F7 | 관리 노동이 결정 노동을 압도 | 2×2=4 |
| F10 | 설명 붕괴 — 룰 설명 15분이 세션 예산을 파괴 | 2×2=4 |
| F11 | 다운타임 — 남의 차례를 기다리는 유휴 시간 | 2×2=4 |

**척도의 소비**(선언만 하면 입장 의례이므로 세 곳에서 실제로 쓴다):
1. **규칙 예산 배분** — 총 14줄 상한. 9점에 최소 2줄, 6점에 1줄, 4점에 0~1줄. 예산 초과분은 **미봉쇄로 기록**한다.
2. **사전 확약 삭제 순서** — 시간·복잡도 초과 시 점수 역순으로 버린다(F7 → F10 → F11 → F2 → …). 실행 중 재협상 금지.
3. **충돌 판정 함수** — 점수 높은 실패의 봉쇄가 이긴다. 이 함수가 C1을 판정했다: 시계(6점)를 푸는 대신 쿼터백(9점) 봉쇄를 지키고 분기 폭을 줄였다.

동점(9점 3개)은 봉쇄에 드는 규칙 줄 수가 적은 쪽을 위로 뒀다 — 채점 후에 붙인 타이브레이크다(자백 참조).

## 문제 정의 / 목표

2~4인이 60분(설명·정리 포함 총 점유시간)에 완주하고, **같은 그룹이 다섯 번째 세션에서도 첫 세션과 같은 밀도로 결정하는** 협동 게임의 규칙 골격과 검증 계획을 정한다. 아트·테마·원가는 범위 밖이다.

## 명시적 가정

- **[전체가 걸림] 대상 테이블에 실력·발언량 편차가 있다(알파가 존재한다).** 틀리면 R3 발언 토큰은 순마찰이 된다. 최저비용 조기 검증: 첫 2세션을 실력이 고른 테이블에서 돌려 라운드당 토큰 소진율을 기록 — 소진율 50% 미만이면 가정 붕괴(*임의 선언*, 첫 2세션 분포로 교체). 폴백: R3만 비활성한 "오픈 테이블 변형" 한 줄, 나머지 불변.
- **[전체가 걸림] 2인은 modal 구성이 아니다.** 틀리면 R9가 인정한 "2인의 역할 상호작용 손실"이 수용 손실이 아니라 핵심 결함이 된다. 조기 검증: 대상 그룹 5팀에 실제 플레이 인원 분포를 묻는다. 폴백: 2인 전용 위협 덱(데이터 추가, 규칙 줄 수 불변).
- 60분은 총 점유시간이다. 틀리면 라운드 수를 재계산한다(12 → 16).
- 물리 컴포넌트만, 앱 없음. 틀리면 기각 대안 A3(실시간)이 부활한다.
- 패배가 재도전 욕구를 죽이지 않는다 — 즉시 리셋이 가능하다면. 틀리면 R7은 F6을 못 막고, 문제는 "조기 종료 후 잔여 시간 처리"로 재분류된다.

## 채택 봉쇄 규칙과 등급

등급: **1 = 구조적으로 발생 불가능** / **2 = 기록되지 않고는 발생 불가능**(기록 장치 명시 필수) / **0 = 에티켓, 채택 안 함**.

| 규칙 | 내용 | 대상 | 등급 |
|---|---|---|---|
| R1 | **동시 비공개 커밋** — 매 라운드 전원이 손패 1장을 뒷면으로 동시에 내고 전원 완료 후 동시 공개. 순차 차례 없음. | F2, F11 | 1 — 마지막 결정자가 존재하지 않으므로 킹메이킹의 매체 자체가 없다 |
| R2 | **숨은 손패 3장** — 공개 금지. (카드 이름 발화 금지는 등급 0이라 채택 안 함 → R3으로 대체) | F1 | 1 — 알파가 타인의 선택지를 알 수 없다 |
| R3 | **발언 토큰** — 남의 카드·행동을 지목하는 발언은 공용 토큰 1개를 앞에 놓고 한다. 라운드당 토큰 = 인원수. 무토큰 지시에 누구든 "무토큰"을 선언하면 그 라운드 팀은 위협 카드 1장을 추가 공개한다. | F1, F3 | **2** — 발화는 물리적으로 못 막는다. 기록 장치 = 무토큰 선언 + 즉시 비용 |
| R4 | **위협 선공개** — 라운드 시작에 위협을 인원수만큼 공개한 **뒤** 커밋한다. 해결에 주사위·추가 뽑기 없음(결정적). | F9 | 1 — 무작위가 결과를 정하는 지점이 없다 |
| R5 | **고정 12라운드 + 커밋창 90초** — 모래시계는 상한이며 하한이 아니다(전원 커밋 즉시 진행). 미완 커밋은 기본값(맨 위 카드 자동 커밋). | F5, F11 | 1 — 총 시간이 산술 상한 |
| R6 | **공용 패배 트랙 1개** — 개인 점수·탈락·개인 생존 없음. 트랙은 위협 해결 실패의 합으로만 오르고 라운드 최대 상승은 인원수. | F2, F3 | **1**(F2) — 개인 점수·탈락이 없으므로 "이미 무관해진 1인"이 생길 수 없다 / **0**(F3) — 산술적 귀속은 없어지지만 비난 발화 자체는 막지 못한다. 이 층위의 판정자는 공격자 4다 |
| R7 | **즉시 리셋** — 패배 트랙이 임계에 닿는 순간 세션 종료를 선언하고 동일 셋업으로 재도전. 복구는 더미 3개 되돌리기. | F6 | 1 — 결정된 패배를 계속 진행하는 절차가 규칙에 없다 |
| R8 | **변주는 데이터로** — 세션마다 바뀌는 것은 목표 카드 2장과 위협 덱 구성뿐, 규칙 텍스트 불변. 목표 2장은 **서로 다른 압박 축을 건드리는 페어링 제약**을 받는다(조합 수가 아니라 압박의 종류가 바뀐다). | F4 | **1도 2도 아님** — 정석 발견을 지연시킬 뿐. 판정은 공격자 2에게만 맡긴다 |
| R9 | **인원 비례 스케일** — 역할 수 = 위협 공개 수 = 커밋 수 = 인원수. 1인당 결정 지분이 인원과 무관하게 일정. | F8 | 1 — 산술 |
| R10 | **상태는 보드 위 마커 3개**(패배 트랙·라운드·공용 자원)이고 세션 중 필기 없음. 모든 상태는 색 + 모양 2중 인코딩. | F7, F12 | 1 — 상태 수가 상한이고, 색 정보 없이도 판독 가능하다 |

합계 10줄 + 목표·승리 조건 2줄 = 12줄(상한 14줄 이내).

**수치 태그** — 14줄 상한: *도출*(설명 8분 ÷ 1줄당 시연 35초), 첫 설명 실측으로 교체. 12라운드: *도출*(12×(90초+60초)=30분 + 설명 8 + 셋업 4 + 정리 3 = 45분, 여유 15분). 커밋창 90초: *임의 선언*, 1차 3세션 커밋 소요 중위값으로 교체. 손패 3장: *도출*(90초에 4인이 협상 가능한 분기 폭 가정), 커밋창 실측과 함께 재산정.

## 봉쇄 충돌 판정

- **C1. R2(숨은 정보) × R5(90초).** 숨은 정보는 협상 비용을 올리고 시계는 그것을 허둥댐으로 바꾼다. 판정: F1(9) > F5(6) → 정보를 열지 않고 **손패를 3장으로 줄여 분기 폭을 깎는다.** 시계는 그대로.
- **C2. R2 × R6(비난 봉쇄).** 숨은 정보는 "왜 말 안 했어"라는 새 비난 축을 만든다. 판정: 정보를 여는 대신 **R3의 토큰 경제가 그 실패를 흡수한다** — 알려주지 못한 것은 개인의 실수가 아니라 라운드당 토큰 수의 결과다. 비난 대상이 사람에서 규칙으로 옮겨간다.
- **C3. R5 × F9(무력감 봉쇄).** 실시간 압박은 "손이 늦어 패배"를 만든다. 판정: 시계는 **커밋 단계에만** 걸고 미완 커밋에 기본값을 준다. 압박은 선택의 질을 낮추되 합법성을 훼손하지 않는다.
- **C4. R8(변주) × F10/F7(설명·관리 예산).** 변주 모듈은 규칙을 늘린다. 판정: 변주는 **셋업 데이터에만** 존재한다. 이것이 삭제 레버다 — 확장 요구가 규칙 줄 수를 건드릴 수 없다.

## 접근 및 단계

번호는 의존성 순서다. S2·S3·S5는 S1의 산술만 공유하는 **병렬 작업**이다(사다리가 아니다).

- **S0. 실패 목록 봉인 + 채점.** 선행: 없음. 검증: 두 사람이 독립 채점해 상위 3개 일치. 불일치면 척도 문장을 고쳐 재채점하고 봉인(설계 시작 후 재채점 금지).
- **S1. 시간 예산 산술.** 선행: S0의 F5·F10 순위. 검증: 종이 시뮬레이션으로 12라운드 상한 계산. → F5.
- **S2. 정보 구조(R1·R2·R3).** 선행: S0의 F1·F2·F3. 검증: 알파 공격 1세션. → F1, F2, F3.
- **S3. 위협 엔진 + 스케일(R4·R9).** 선행: S1의 라운드 상한. 검증: 2인·4인 각 1세션에서 1인당 커밋 수 편차 측정. → F9, F8.
- **S4. 셋업 데이터화(R8).** 선행: S3. 검증: 변주 3종을 만든 뒤 규칙 텍스트가 12줄에서 변하지 않았음을 확인. → F4(부분).
- **S5. 붕괴·즉시 리셋(R7) + 상태 축소·2중 인코딩(R10).** 선행: S1. 검증: 조기 패배 세션에서 리셋~재개 실측 + 흑백 복사한 보드로 상태 판독 성공. → F6, F7, F12.
- **S6. 충돌 판정 라운드.** 선행: S2~S5 전부. 검증: C1~C4의 판정과 근거 점수를 기록. 미판정 충돌이 남으면 반복.
- **S7. 적대적 검증.** 선행: S6. 아래 4종.
- **S8. 등급표 확정.** 선행: S7. 성공한 공격이 있으면 해당 등급을 강등하고 이력을 남긴다.

### S7 — 적대적 검증 (공격자 인센티브)

봉쇄가 구조인지 예의인지는 **실패를 일으키라고 지시받은 테스터**만 판정한다. 성공한 공격은 공격자 이름으로 기록되고(현상금), 해당 등급이 강등된다.

- **공격자 1 — 알파.** 매 라운드 **각 플레이어별 지시를 소리 내어 선언**하고 2명 이상이 그대로 커밋하게 만든다. 지시 발화를 임무로 강제해야 아래 판정 기준 1의 불일치율이 정의된다.
- **공격자 2 — 솔버.** 동일 셋업 3세션에서 같은 오프닝 스크립트로 3승. 성공하면 R8은 F4를 봉쇄하지 못한다.
- **공격자 3 — 시계 파괴자.** 규칙을 어기지 않고 총 점유시간을 75분 초과시킨다(판정 기준 2의 70분 + 관찰 오차 5분, *도출*).
- **공격자 4 — 책임 전가자.** 패배 후 테이블 과반이 "이 사람 때문"이라고 지목하게 만든다. R6이 F3에 대해 등급 0이므로, 이 공격의 결과가 F3 봉쇄의 유일한 판정 자료다.

## 대안과 기각 사유

- **A1. 캠페인/레거시.** F4를 가장 강하게 봉쇄한다. 기각: 유동 인원 + 60분 픽업과 양립 불가(결석자 처리 규칙이 예산 초과). **부활**: 대상이 고정 4인 그룹으로 재정의되고 세션 연속성이 보장될 때.
- **A2. 히든 트레이터.** 다운타임·쿼터백을 크게 완화한다. 기각: F2·F3을 새로 **생성**한다 — 상위 실패를 만들어 하위 실패를 막는 거래. **부활**: 실패 목록에서 F3이 제거될 때(예: 서로 모르는 컨벤션 테이블).
- **A3. 전면 실시간 진행.** 다운타임 0, 쿼터백 봉쇄 강력. 기각: 앱 의존이 가정을 위반하고 2인에서 압박이 붕괴한다. **부활**: 앱 동반을 허용하기로 결정될 때.

| C1 판정으로 손패 3장이 되어 결정이 빈곤해짐 | S3에서 커밋 1회당 유효 선택 수를 계수. 3 미만이면(= 손패 3장이 전부 무의미해지는 하한, *도출*) 손패 4장 + 커밋창 재산정 |
| R7 즉시 리셋이 "짧은 판 = 손해" 감각을 만듦 | 12라운드 세션은 30분이므로 재도전까지 60분 예산 안에 들어간다 |
| **누락 점검 스윕에서 회수, 미채점** — 언어 의존(카드 텍스트가 많으면 F10 재발), 토큰 분실 | 위협 카드는 아이콘 문법(텍스트는 목표 카드 2장에만), 토큰은 임의 대체물 허용(수량만 규정). 둘 다 컴포넌트 명세 단계의 필수 항목으로 이월하되 F 번호는 없다(자백 참조) |

## "완료"의 판정 기준

1. **(핵심)** 공격자 1을 투입한 4인 3세션에서, 알파가 **선언한 지시**와 실제 커밋의 불일치율이 알파 외 모든 플레이어에게서 30% 이상이다. 측정: 커밋 공개 시점에 기록자 1인이 지시/커밋 쌍을 표에 기록. 봉쇄가 지시 자체를 없애면 지표가 정의되지 않으므로, 지시 발화를 공격자 임무로 강제해 지표를 봉쇄와 독립시켰다. 30%는 *임의 선언*, 3세션 실측 분포로 교체.
2. 6세션 전부에서 설명 시작~정리 완료가 70분 이내(60분 목표 + 학습 여유 10분, *도출*). 측정: 관찰자 1인, 스톱워치.
3. 커밋창 30초 경과 시점 무작위 3회 스냅샷에서 "아무 결정도 하지 않는 플레이어" 0명. 측정: 관찰자 육안 계수.
4. 공격자 2가 동일 셋업 3세션을 같은 오프닝으로 3승하지 못한다. 실패하면 F4를 미봉쇄로 확정하고 A1 부활 조건을 재검토한다.
5. 조기 패배 세션에서 리셋~재개 30초 이내(*임의값, 첫 실측으로 교체*). 2인·4인 1인당 커밋 수 편차 20% 이내(*임의값, 첫 측정으로 교체*). 측정: 스톱워치 + 커밋 기록표.
6. 보드·카드를 흑백 복사한 사본만으로 4인이 12라운드를 완주하며 상태 판독 질문이 0회다. 측정: 관찰자 계수(F12 봉쇄 확인).

## 프레임 이탈 및 관성 회귀

- **누락 스윕 회수물의 절반만 채점했다.** 색약은 F12로 표에 넣고 R10에 봉쇄를 붙였지만, 언어 의존과 토큰 분실은 리스크 표에 완화책 + 컴포넌트 단계 이월만 있고 **F 번호가 없다** — 즉 규칙 예산 경쟁에 참여하지 못했다. 리뷰어라면 여기를 친다: 스윕이 찾은 항목을 척도에 넣을지 말지를 내가 임의로 갈랐다.
- **동점 처리가 사후 편의였다.** 9점이 3개 나온 뒤 "규칙 줄 수가 적은 쪽"을 타이브레이크로 붙였다(시작점 섹션 마지막 줄). 채점 전에 고정한 규칙이 아니므로 F4가 F1·F3 아래에 놓인 것은 내 선호일 수 있다.
- **9점 실패 두 개에 등급 있는 봉쇄가 없다.** F4는 R8에 페어링 제약을 더해도 등급 1이 아니고, F3은 R6이 발화 층위에서 등급 0이다(R3의 2등급이 부분만 덮는다). 둘 다 표에 등급 2로 적으면 문서가 매끄러워졌고, 그 유혹을 기록한다.
- **도메인 정석에 착지했다.** "숨은 손패 + 제한된 소통"은 협동 게임 장르의 기성 답이다. 프레임이 실제로 뒤집은 것은 두 곳뿐이다: C1(시계를 풀지 않고 손패를 줄인 판정)과 R4(무작위를 결과가 아니라 문제 정의로만 쓴 결정).
- **번호가 의존성보다 서사를 따랐다.** S0~S8은 오름차순 사다리로 읽히지만 S2·S3·S5는 병렬이다. 서두 한 줄로 완화했을 뿐 번호 체계 자체는 관성이다.
