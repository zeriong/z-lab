# 지식 상품화 3트랙 병렬 설계 — 기술서 / 온라인 강의 / 유료 뉴스레터
- 추론 프레임: option-parallel
- 한 줄 요약: 세 형식을 동일 골격으로 완결 설계하고, 표본 제작 프로브의 에너지 반응 델타로 선택을 실행자에게 넘긴다 — 추천 대신 판독 규칙·공통 코어·전환 마감을 박아둔다.

## 프레임이 요구하는 시작점 — 트랙별 생존선 사전 점검 (0단계, 30분)

세 트랙이 모두 생존선을 통과할 때만 이 문서가 유효하다. 하나라도 미달이면 선택 문제가 아니라 제약 문제이므로 통과한 트랙만으로 다시 써야 한다. 예/아니오로만 채운다.

| 트랙 | 생존선 (전부 예여야 통과) | 규모 수치의 근거 |
|---|---|---|
| 기술서 | 공개한 2,000자 이상 기술 글 3편 / 12장으로 쪼갤 주제 1개 / 근로계약의 겸업·직무발명(저작권 귀속) 조항 저촉 없음 | 12장 = 상용 기술서 관행 최소 분량(관행 인용, 출판사 회신으로 대체) |
| 온라인 강의 | 30분 설명 녹음을 재녹음 3회 이내 종료 / 마이크·화면녹화·편집 도구 보유 / 겸업 조항 저촉 없음 | 8시간 = 유료 플랫폼 최소 분량 관행(관행 인용, 심사 기준으로 대체) |
| 유료 뉴스레터 | 발송 채널·결제 수단 개설 가능 / 격주 마감 8회분 캘린더 여유 / 겸업 조항 저촉 없음 | 8회 = 유료 전환 전 신뢰 축적 최소치(임의 선언, 4회 발행 후 이탈률로 재설정) |

**이 점검이 뒤집은 결정: 일정의 직렬화.** A2(주 12시간)로 프로브 18시간과 공통 코어 72시간을 병행하면 주당 20시간이 필요해 세 트랙이 동시에 "캘린더 여유"를 위반한다. 그래서 프로브(1~2주) → 공통 코어(3~8주)를 **직렬**로 놓고 결정일을 8주차 말로 미뤘다. 겸업·IP도 리스크가 아니라 여기 있다 — 저촉되면 세 트랙이 함께 무효가 되는 벽이다.

## 문제 정의 / 목표

어느 형식이 "좋은가"는 시장 데이터 없이 판정 불가지만, **어느 파이프라인이 실행자를 가장 덜 소모시키는가**는 2주 안에 측정 가능하다. 목표: 26주차에 선택 트랙에서 제3자 기록 1건. 수요·판매량·품질은 측정 대상이 아니다.

## 명시적 가정

- **A1 (전체가 걸림): 세 트랙 모두 0단계를 통과한다 — 즉 선택 문제다.** 틀리면 프레임 자체가 무효. 가장 싼 검증 = 0단계 30분 표. 폐기 경로 = 통과 1개면 프로브 생략 후 즉시 착수, 2개면 프로브를 2트랙 × 6시간으로 재분배.
- A2: 주 가용 12시간(임의 초기값, 프로브 실소요로 대체). 틀리면 모든 주차 라벨이 스케일된다. 줄일 때는 회차가 아니라 트랙 수를 줄인다 — 회차를 줄이면 델타 판독이 불가능해진다.
- A3: 에너지 반응이 완주 가능성의 대리지표다. 틀리면 판독이 취향 조사로 퇴화 → 16주차에 판독 축을 마감 준수율로 교체.
- A4: 소재 원장이 세 형식에 재사용된다. 틀리면 연기 기간의 가치가 사라짐 → 연기 6주를 3주로 줄이고 결정일을 앞당긴다.

## 세 트랙 — 동일 골격 완결 설계

단위 경제 값은 세 칸 모두 관행 인용 + 임의 초기값이므로 **트랙 간 수익 비교에 쓰지 않는다**(트랙 내부 규모 감각 전용). 산출 단위 규격(2,500자·8분·1,800자)도 임의 초기값이며 프로브 1회차 실소요로 대체한다.

| 항목 | 기술서 | 온라인 강의 | 유료 뉴스레터 |
|---|---|---|---|
| 산출 단위 | 절(2,500자 + 코드) | 클립(8분 + 예제 레포) | 1회분(1,800자) |
| 최소 완주 규모 | 12장 / 투고본 3장 + 목차 + 제안서 | 8시간 / 유료 공개 1모듈 | 격주 8회 무결 발행 후 유료 전환 |
| 파이프라인 | 개요 → 초고 → 예제 검증 → 편집 반려 → 재구성 → 교정 | 스크립트 → 녹음 → 편집 → 자막 → 플랫폼 심사 | 소재 선정 → 초고 → 발송 테스트 → 발행 → 문의 응대 |
| 단위 경제 | 38,000원 × 인세 10%(관행, 계약서로 대체) = 3,800원/부 | 88,000원 × 정산율 60%(관행, 플랫폼 계약으로 대체) = 52,800원/명 | 월 6,000원 × 정산율 85%(관행, PG 계약으로 대체) = 5,100원/월·명 |
| 죽는 구간 | 완성한 3개 절을 반려로 버리고 재구성하는 주 | NG 재녹음 + 편집 60분(창작 아닌 노동) | 소재 고갈 상태로 맞은 두 번째 마감 |
| 완주 판정 | 출판사 투고 접수 회신 1건 | 유료 등록 1건 | 유료 구독 1건 |

## 접근 및 단계 (주차 라벨은 A2의 투영)

1. **0단계 생존선 점검.** 선행 없음. 검증: 9칸이 예/아니오로 채워짐. 미달 시 A1 폐기 경로.
2. **1단계 프로브 1회차(3트랙 병렬, 각 4시간 — A2를 3분할한 파생값).** 0단계 통과를 소비. 산출 단위 1개를 파이프라인 **전 구간** 통과시키고 죽는 구간을 반드시 포함한다: 책은 제3자에게 구조 반려를 받고 재구성, 강의는 편집·자막까지, 뉴스레터는 3일 간격 2회 마감. 검증: 산출물 3개 + 죽는 구간 증거(재구성 diff, 편집 타임라인, 2회 발행 로그).
3. **2단계 프로브 2회차(각 2시간, 1회차의 역순)** + 판독표 봉인. 1단계 출력을 소비. 역순은 피로 누적·신규성 감쇠를 트랙 차이로 오독하지 않기 위한 장치다. 검증: 18칸(3트랙 × 3지표 × 2회차) + 판정문 1문장.
4. **3단계 공통 코어(3~8주).** 프로브와 직렬, 트랙과 무관 — 선택을 연기할 수 있는 기간이자 어느 트랙도 버리지 않는 자산을 쌓는 기간. 산출: ① 소재 원장 40항목(항목마다 "독자가 틀리게 아는 것 / 실행 가능한 예제 / 검증 방법") ② 예제 레포 + 실행 로그 ③ 자체 이메일 리스트 + 랜딩 1장. 40 = 최대 요구인 책 12장 × 3절 = 36 + 여유 4(파생). 검증: 무작위 5항목을 세 형식으로 변환한 15칸 초안.
5. **4단계 결정일(8주차 말).** 3단계 완료 + 봉인 판독표를 소비. 봉인을 열고 판독 규칙으로 1트랙 확정. 검증: 트랙명 + 인용한 규칙 문장 1줄.
6. **5단계 트랙 전용 파이프라인(9~24주).** 4단계 출력을 소비. 착수 시 전환 창·정지 조건을 캘린더 등록하고, 산출 단위를 하나 완료할 때마다 복귀 지연을 계속 기록한다(정지 조건의 데이터원 — 프로브 2회로 끝나면 정지 규칙은 데이터가 없다).
7. **6단계 전환 창(16주차 말, 1회).** 기본값은 유지. 전환은 비용표를 상태값으로 채우고 사유 1문장을 남길 때만 가능. 16주차 = 세 트랙 모두 지출이 회수 불가로 바뀌는 시점(계약 체결 / 장비·학습 완료 / 유료 전환 개시) 직전이라는 파생값.
8. **7단계 완주 판정(26주차).** 5·6단계 출력을 소비.

## 에너지 반응 판독 규칙

각 회차가 **끝난 뒤** 24시간 내에 3지표를 기록한다. ① 복귀 지연 — 자발적으로 다시 손대기까지의 시간 ② 마감 직후 2시간 가동 가능(예/아니오) ③ 요청되지 않은 초과 작업 발생(예/아니오). 기량·품질은 기록하지 않는다. 1주차 품질은 노출 편차의 함수다.

- 주 판독은 트랙 간 절대 비교가 아니라 **회차 델타(2회차 − 1회차)**다. 복귀 지연 델타가 가장 작은 트랙이 소모 최소다. 절대 비교는 실행 순서와 신규성에 오염되고, 델타는 반복 마감을 이미 겪은 트랙이 유리해지는 편향까지 상쇄한다.
- **무점화:** 1·2회차 순위가 뒤집히거나 델타 차이가 6시간 미만이면 "판정 불가"(6시간 = 임의 선언, 결정일에 실측 복귀 지연 최솟값의 절반으로 재설정).
- **기본 트랙 규칙(사전 선언, 출력은 결정일에 계산):** 판정 불가면 기본 트랙은 전환 비용표의 **복귀 비용 열이 최소인 트랙**이다. 그 열은 결정일에 실행자 상태값(계약 체결 여부 / 장비 구매·학습 여부 / 유료 구독자 존재 여부)으로 채운다. 동률이면 원장에서 즉시 변환 가능한 항목이 최다인 트랙. 이 문서는 어느 트랙도 기본값으로 지명하지 않는다.
- **정지 조건(하강은 정상이다):** 복귀 지연이 연속 2회 168시간을 넘으면 트랙 정지 판정(168시간 = 최단 발행 주기 1주 초과 = 파이프라인이 이미 멈춘 상태, 파생).

## 전환 마감과 전환 비용

전환 창은 16주차 말 **1회** 상한(임의 선언 — 상한이 없으면 트랙 쇼핑이 되고, 2회 이상이면 어느 트랙도 최소 완주 규모에 닿지 못한다). 창을 지나면 완주 또는 정지만 남는다.

| 전환 방향 | 매몰되는 것 | 이월되는 것 | 복귀 비용(결정일 상태값) |
|---|---|---|---|
| 기술서 → 강의/뉴스레터 | 출판사 협의, 계약 시 선인세·신뢰 | 원고 → 스크립트·발행분 | 계약 전이면 시간뿐 / 계약 후면 금전 + 평판 |
| 강의 → 기술서/뉴스레터 | 장비 비용, 편집 학습 시간 | 스크립트, 예제 레포 | 미구매면 시간뿐 / 구매·학습 후면 회수 불가 |
| 뉴스레터 → 기술서/강의 | 발행 리듬, 구독자 신뢰 | 발행분 → 절·클립 직결 | 유료 구독자 0명이면 시간뿐 / 1명↑이면 환불 의무 + 제3자 손실 |

## 대안과 기각 사유

- **3트랙 동시 병행 완주.** 기각: A2에서 트랙당 주 4시간이면 어느 트랙도 최소 완주 규모(12장 / 8시간 / 격주 8회)에 닿지 못한다. 부활 조건: 주 30시간 확보, 또는 편집·교정 외주 월 80만원(임의 초기값) 확보 시 2트랙 병행 재검토.
- **프로브 없이 즉시 착수.** 기각: 프로브 18시간은 트랙 전용 매몰 비용(최대 96시간)의 1/5 이하인데 전환 창은 1회뿐이라 오선택 회복 경로가 없다. 부활 조건: 세 형식 중 2개를 이미 유료로 완주했다면 프로브를 기억으로 대체하고 0단계에서 결정일로 직행.

## 리스크와 완화

점검한 범주: 계약·겸업/IP, 세무·결제, 저작권·라이선스, 플랫폼 의존, 건강·번아웃, 가족·시간, 측정 오염, 시장 수요. 착지 지점 — 계약·겸업/IP는 0단계 생존선(리스크가 아니라 벽). 측정 오염은 순서 역전 + 델타 판독. 플랫폼 의존은 공통 코어의 자체 이메일 리스트(세 트랙 공통의 독립 채널). 세무·결제는 유료 판매 개시 전(16주차 이전) 통신판매업 신고·부가세 확인 게이트. 건강은 168시간 정지 조건과 5단계의 계속 기록. 시장 수요는 측정하지 않는 항목으로 남기고, 판독 결과를 수요 근거로 인용하지 않는다.

## "완료"의 판정 기준

1. **(실측) 26주차에 선택 트랙에서 제3자 시스템의 기록 1건이 존재한다** — 투고 접수 회신, 유료 등록, 유료 구독 중 하나. 자기 평가로는 충족되지 않는다.
2. 판독표 18칸이 채워지고 판정문 1문장(또는 "판정 불가" + 기본 트랙 규칙 적용 결과)이 남는다.
3. 16주차 전환 창에 복귀 비용 열이 상태값으로 채워진 비용표와 유지/전환 판정 1문장이 존재한다.
4. 8주차에 원장 40항목 중 무작위 5항목 × 3형식 = 15칸 변환 초안이 존재한다.
5. (등가성 규칙) 골격 표의 트랙별 칸이 6개로 동일하고, 단위 경제 칸이 트랙마다 3개 수치(가격 × 정산율 = 단위 수익)를 가지며, 트랙 서술 길이 비가 1.15 이하다(임의 선언).

## 프레임 이탈 / 관성 회귀

- 단계 1~7이 병렬 관계가 아닌데 오름 사다리로 번호 붙었다. 3단계는 병렬로 놓으려던 것을 산수 때문에 직렬로 내린 것이라, "연기 기간"이 선택 유보가 아니라 단순 대기로 읽힐 여지가 남는다.
- §단계 7의 16주차 근거는 관측값이 아니라 내가 배치한 일정에서 역산한 값이다. 종속 유도로 서술했지만 캘린더 값에 가깝다.
- 기본 트랙 규칙은 지명 없이 절차만 남기도록 고쳤지만, 규칙을 "복귀 비용 최소"로 고른 선택이 특정 형식에 유리하지 않다는 증명은 없다. 리뷰어라면 §에너지 반응 판독 규칙의 이 항목을 먼저 공격해야 한다.
- 가장 약한 섹션은 §리스크와 완화다. 세무·결제를 게이트 한 문장으로 처리했고 실행자가 그 문장만으로 움직이지 못한다. 저작권·라이선스와 가족·시간은 이름만 올랐고 착지 지점이 없다.
- 프로브 4시간/2시간을 트랙마다 같게 준 것은 등가성 규칙의 요구였고, 형식마다 1단위 생산 시간이 다르다는 사실과 충돌한다. 등가성이 형식 등가에 그친 지점이다.
- §트랙 골격의 "플랫폼 심사"는 이름만 있고 게이트도 검증도 없다. 책의 편집 반려는 프로브 장치를, 뉴스레터의 유료 전환은 세무 게이트를 얻었는데 이 항목만 맨몸이다.
