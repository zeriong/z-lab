# 가입 후 첫 주 이탈률 60% — 원인 특정 조사

- 추론 프레임: hypothesis-loop
- 한 줄 요약: 1차 산출물은 개선안이 아니라 **재현 레시피**다 — 60%를 계측 산출물 가설부터 정산하고, 기존 로그만 쓰는 저비용 가설 실험을 병렬로 돌려 사전 등록된 조건으로만 기각·승격한다.

## 프레임이 요구하는 시작점 — 관찰 사실과 추측의 분리

내 반사적 습관은 퍼널 단계별 이탈률을 뽑고 낙차가 가장 큰 단계에 개선안을 붙이는 것이다. 프레임은 이를 금지한다. 낙차는 원인이 아니라 **단계 정의의 산출물**이고(단계를 쪼개면 낙차는 이동한다), 처방은 원인 특정 이후에만 의미가 있다.

**관찰 사실** — "가입 후 첫 주 이탈률 60%"라는 **보고된 수치가 존재한다.** 그 이상은 없다. 정의(모수·복귀 이벤트·기준 시각), 산출 쿼리, 관측 기간, 비교 기준선 중 확인된 것이 없다.

**추측** — ① 이 60%가 실제 사용자 행동이다 ② 하나의 현상이다 ③ 비정상이다 ④ 원인이 온보딩 안에 있다. 전부 가설이며, ①은 행 0에서 ③은 게이트 G0에서 다른 어떤 실험보다 먼저 정산된다.

**좌표계 회의** — 사전 등록 대체 좌표 4종: (가) 경과일 → 로컬 시각·요일 (나) 달력일 → **세션 서수**(붕괴는 1세션과 2세션 *사이*일 수 있다) (다) 계정 → 사람(공유·재가입) (라) 절대 이탈률 → **유입 믹스**: 세그먼트별 잔존이 모두 개선됐는데 총계가 악화되는 심슨 역설이면 원인은 온보딩이 아니라 획득 구성비다. (라)가 참이면 온보딩 개선안 전체가 헛일이므로 **R1의 의무 확인 항목**이다.

## 문제 정의 / 목표

**1차 목표는 원인 특정이며 개선이 아니다.** 완료 산출물은 "조건 C를 만족하는 코호트의 D7 미복귀율이 나머지보다 Δ 이상 높다"를 제3자가 독립 재현할 수 있는 **재현 레시피 1건**, 또는 정식 발행된 "원인 미특정" 결론이다.

**진입 자격 게이트 G0** (착수 전, 반나절). 두 질문에 답하지 못하면 조사를 열지 않는다.
1. *이상 현상인가?* 동일 정의로 계산한 내부 최우량 코호트(과거 12개월 최상 월 또는 최상위 채널)의 미복귀율이 60%보다 Δmin 이상 낮은가. 낮으면 이상 현상 성립. 아니면 60%는 정상 상태이고, 이것은 원인 조사가 아니라 제품·시장 문제다(조사 종료, 별건 발행).
2. *관측 런웨이가 있는가?* 조직이 3주간 고치지 않는 것을 감당하는가(3주 = R0·R1 약 6영업일 + R2 홀드아웃 관측 2주, 파생). 원인 특정을 선언할 **판정 권한자 1인**을 지명해 문서에 이름을 남긴다. 감당 못 하면 타임박스를 R1까지로 축소하고 소멸 기본값을 조기 발화시킨다.

**Δmin — 모든 임계값의 뿌리:** Δmin = 두 군 비율차의 2×표준오차. R0에서 실제 주간 가입 수 N과 기저 잔존율 p로 **계산해 확정**하고 원장 머리에 기입한다(산출: 데이터 분석 담당, R0 1일차). 격차 임계는 전부 Δmin으로만 표기한다 — 초안의 감각값 "15%p"가 서 있던 자리다. Δmin 확정 전에는 어떤 기각도 선언하지 않는다.

## 명시적 가정

1. **가입·세션·핵심 행동 이벤트가 사용자 단위로 조회 가능한 기존 로그가 존재한다.** — 틀리면 저비용 병렬 라운드가 성립하지 않고 조사가 계측 배포 대기로 바뀐다. 가장 싼 조기 검증: R0 1일차 1시간, 임의 가입자 5명의 가입~D7 타임라인 수동 복원(복원 실패 자체가 결과다). 대체 경로: R1을 "관측 가능성 조사"로 교체하고 결제·문의·이메일 발송 로그·리뷰만으로 축소 원장을 돌린다.
2. 조사 기간 중 가입 플로우·온보딩·획득 캠페인을 **동결**한다 — 틀리면 코호트 비교가 오염되고 홀드아웃 예측이 무효다(변경 시 해당 코호트를 원장에서 제외하고 라운드 번호를 올린다).
3. 이탈자의 로그가 보존돼 있다 — 틀리면(탈퇴·삭제 요청 결손) 이탈 코호트가 체계적으로 지워져 모든 실험이 생존자만 본다. 결손율을 행 0의 정산 축에 포함한다.
4. 주간 가입 수가 Δmin을 의미 있게 만들 만큼 있다 — 틀리면 R1의 정답은 전부 "판정 불가"이며 소멸 기본값으로 직행한다.

## 접근 및 단계 — 가설 원장과 게이트

**행 0 우선 규칙: H0이 정산되기 전에는 다른 어떤 결과도 해석하지 않는다**(계산은 병렬로 해도 되고 판정만 금지). 계측이 유죄면 나머지 데이터는 전부 오염이다.

| 행 | 가설 | 사전 등록 기각 조건 | 비용·데이터원 |
|---|---|---|---|
| **H0** | 60%는 계측·정의·쿼리의 산출물이다 | 4축(중복·봇 계정 / 기준 시각 UTC↔로컬 / 복귀 이벤트 정의 3종 / 로그 결손율)으로 재계산해 60%에서 **Δmin/3 이내**면 기각(수는 실재) | 저 — 쿼리, 배포 0 |
| H1 | 유입 품질(특정 채널·기기 집중) | 채널별 미복귀율 최상–최하 격차 < Δmin **이고** 최악 3채널 제거 후 총계 변화 < Δmin/3 → 기각 | 저 — 쿼리 |
| H2 | 첫 세션의 구조적 차단(인증메일·SMS 미도달, 권한 거부, 빈 상태, 무료 한도) | 이탈자의 *마지막 이벤트*가 단일 스텝에 몰리는 집중도가 기저 기대치의 2배 미만 → 기각 | 저–중 — 로그+발송 로그 |
| H3 | 가치 도달 비용(첫 성공 행동까지의 시간·단계) | 첫 성공 행동 도달군/미도달군의 D7 잔존 격차 < Δmin → 기각. *생존자 편향: 통과해도 상관일 뿐, 승격은 G3만* | 저 — 쿼리 |
| H4 | 기대 불일치(광고 약속 vs 첫 화면) | 이탈 코호트의 첫 탐색 질의·문의·리뷰에서 "미보유 기능" 지목 비율이 잔존 코호트와 Δmin 이상 차이나지 않으면 기각 | 중 — 검색·문의·리뷰 |
| H5 | 이탈이 아니다(1회 목적 달성형 사용) | 이탈자 중 핵심 작업 1회 이상 완료 비율 < 20% → 기각 | 저 — 쿼리 |

**임계값 태그.** Δmin·Δmin/3·Δmin/2는 파생. *임의값 3건 + 대체 트리거* — "2배"(H2) → R0의 스텝별 이벤트 부재 분포 상위 5% 분위수; "20%"(H5) → R0의 전체 가입자 D7 내 핵심 작업 완료율(이탈자 완료율이 전체와 근접하면 완료가 복귀를 예측하지 못한다는 뜻); "3채널"(H1) → 채널 수의 상위 20%. 대체자는 데이터 분석 담당, 시점은 R1 판정 전. R1 소요 5영업일도 임의값이며 R0에서 측정된 쿼리 1건 실소요 × 5로 대체한다.

**단계** (선행조건 / 검증 / 기여):
- **R0 정의 정산.** 선행: G0 통과. 검증: H0 판정 + Δmin 확정 + 임의값 3건 대체. 기여: 이후 모든 판정의 해석 가능성. H0이 기각되지 **않으면** 결론은 "숫자가 틀렸다"이고 조사는 계측 수정으로 끝난다(유효한 결과다).
- **R1 저비용 병렬 라운드.** 선행: Δmin 확정(H0 판정과 병행 계산 가능, **H1~H5는 서로 독립·병렬**). 신규 계측 배포 금지 — 기존 로그만. 검증: 다섯 기각 조건 일괄 판정 + 좌표 (라) 의무 확인.
- **게이트 G1 — 세 출구.** ① 생존 가설 ≥1 → R2 ② 전부 기각 → 소멸 기본값 ③ 판정 불가(표본·데이터 부족) → 좌표 재설정 후 R1을 새 번호로 1회만 재실행.
- **임계값 수정 규칙(복귀 경로).** 데이터를 본 뒤 임계값을 고치고 싶어지면 해당 가설은 자동으로 **"보류"로 강등**되고 사유가 원장에 기입되며, 새 라운드 번호에서만 재판정한다. 사후 해석이 통과할 수 있는 유일한 통로가 이것이다.
- **R2 / 게이트 G2 — 홀드아웃 예측(승격 1차 관문).** 선행: G1 ①. 분석에 쓰지 않은 다음 2주 가입 코호트에 대해 봉인 예측문 1건 제출: "조건 C를 만족하는 신규 가입자의 D7 미복귀율이 나머지보다 Δmin 이상 높다"(2주 = D7 관측 7일 + 축적 7일, 파생). 검증: 방향·크기 동시 적중. 불발이면 원장에 기록하고 R1으로 복귀.
- **게이트 G3 — 유도·절제 재현(승격 2차 관문).** 선행: G2 적중. **자연 실험 우선** — 과거 릴리스·장애·기존 A/B 토글에서 조건 C가 켜졌다 꺼진 구간을 로그에서 찾아 이탈률 동반 변화를 본다. 자연 실험이 없을 때만 능동 유도를 쓰고, 신규 가입자의 소수 비율로 제한하며 판정 권한자의 사전 승인을 남긴다. 검증: 주입 시 재현, 제거 시 감소. *효과 크기를 성과로 보고하지 않는다 — 목적은 인과 확인이다.*
- **소멸·판정 불가 기본값.** R2까지 전부 기각·보류이거나 타임박스 소진 시: ① **"원인 미특정"을 정식 결론으로 발행**한다(유효한 결과다) ② **단일 현상 전제를 심문**한다 — 60%를 하나의 현상으로 본 전제를 폐기하고 코호트를 3분할(채널 / 유입 의도 / 기기·국가)해 원장을 분할별로 재실행 ③ 그래도 안 되면 조사를 닫고 상시 계측(정의 동결 + 코호트 대시보드)으로 전환하며, 개선 착수는 저위험 1건에 한정하고 **실험이 아니라 운영으로 표기**한다.

## 대안과 기각 사유

- **즉시 온보딩 리디자인 + A/B.** 기각: 원인 미특정 상태의 A/B는 60% 중 무엇을 건드리는지 모른 채 표본을 소모하고 조사 코호트를 오염시킨다. 부활: G2 적중 후 승격 가설의 절제 실험으로, 또는 소멸 기본값 발화 시 저위험 1건.
- **이탈자 인터뷰·설문 우선.** 기각: 자기보고는 사후 서술이라 **사전 등록이 불가능**하고 접촉 자체가 개입이다. 부활: R1에서 H4가 유일 생존 가설로 남을 때, 접촉 코호트를 홀드아웃에서 제외하고 실행.
- **세션 리플레이·신규 계측 전면 도입.** 기각: 가설 없는 계측 산포이며 배포 대기가 R1을 지연시킨다(비용 원장의 저비용 병렬 선행과 충돌). 부활: R1에서 H2가 생존해 특정 스텝이 지목되면 그 한 스텝에만.
- **퍼널 단계별 최대 낙차 처방.** 기각: 낙차는 단계 정의의 산출물이다. 부활: 원인 도구가 아니라 좌표 후보(세션 서수)로만.

## 리스크 & 완화

- **조기 수렴**(선호 가설만 파기) → R1 다섯 판정 완료 전 단독 심화 금지. **사후 해석** → 임계값 수정 규칙 + 봉인 예측문.
- **표본 부족** → Δmin이 자동 노출하며 부족하면 "판정 불가"가 정답. **생존자 편향**(H3) → 승격은 G2·G3만.
- **조직 압력**("원인 말고 대책") → G0의 런웨이 질문, 지명된 판정 권한자, 축소 타임박스. **조사 비용** → R1 전량이 기존 쿼리, 계측 개발 0.

**누락 범주 점검 스윕**(전혀 언급하지 않은 범주 → 착지점): 법·규제(삭제 요청에 따른 로그 결손 → 가정 3, 행 0의 4축), 과금 벽(무료 한도 → H2), 국가·언어·접근성(→ 좌표 (다)(라), 소멸 기본값의 3분할 축), 플랫폼(스토어 심사·리뷰 → H4 관측원), 인프라 장애(가입 주간 사고 → 좌표 (가) 달력일 정렬), 조직(판정 권한자 → G0), 이메일 도달률(→ H2 발송 로그 대조).

## "완료"의 판정 기준

1. **(실측 판정 문장 — 의무)** 조사에 참여하지 않은 엔지니어 1인이 재현 레시피만 읽고 조건 C를 만족하는 코호트를 독립 추출했을 때, 그 코호트의 D7 미복귀율이 레시피에 적힌 값과 **Δmin/2 이내**로 일치한다.
2. 봉인 예측문 1건이 분석에 쓰이지 않은 다음 2주 코호트에서 방향·크기 모두 적중했다 — **또는** 불발 사실이 원장에 기록되고 "원인 미특정"이 정식 결론으로 발행됐다.
3. 원장의 모든 행이 기각·보류·승격 중 하나로 종결돼 있고 빈 칸이 없다.
4. G3의 자연 실험 또는 승인된 유도·절제 중 하나가 실제로 실행되어 결과가 기록됐다.

## 프레임 이탈 / 관성 회귀

- **가장 약한 절:** H4의 기각 조건. "미보유 기능 지목 비율"은 텍스트 분류를 전제하는데 분류 기준을 정하지 못했고, Δmin으로 감싸 수치 형태만 갖췄다. 리뷰어라면 이 칸을 먼저 공격해야 한다.
- **관성 회귀:** R0 → R1 → R2 → G3 표기가 오름차순 파이프라인으로 읽힌다. 복귀 경로(임계값 수정 규칙, G1 출구 ③, G2 불발 시 R1 복귀)를 규칙으로 박아 완화했지만 문서 형태는 루프가 아니라 계단이다.
- **관행 선택:** G3에서 능동 유도 대신 자연 실험을 1순위로 둔 것은 프레임의 요구가 아니라 조직 수용성을 택한 결과이며, 자연 실험이 없으면 승격 근거가 G2 하나로 얇아진다.
- **하중 가정:** 가정 1에 조사 전체가 걸려 있다. 1시간 검증과 대체 경로를 붙였으나, 대체 경로(축소 원장)로는 H1·H3·H5를 판정할 수 없다는 공백은 남았다.
