# 로그 — 52 API p99 스파이크 (hypothesis-loop) [Opus 5]

## 진입 시 사고

과제를 읽자마자 떠오른 것은 도구 목록이었다. APM 트레이스, GC 로그, 풀 메트릭, steal time. 관성적 습관은 "관측 인프라를 나열한 뒤 그것으로 무엇을 볼지 정한다"는 순서이고, 이 순서는 계측을 가설보다 앞세운다 — 프레임이 실패 모드로 명시한 "가설 없는 계측 살포"가 그것이다.

프레임이 교정한 지점은 둘이다. 첫째, **원장이 도구 목록보다 먼저 온다.** 과제가 지정한 다섯 개(GC, 풀 고갈, 이웃 소음, 재시도 폭풍, 페이로드)는 이미 다섯 행이었지만 프레임은 0행 — "숫자 자체가 집계 산물" — 을 강제했다. 0행은 추가되는 행이 아니라 **다른 모든 행의 해석을 봉인하는 행**이다. 이 규칙을 쓰는 순간 1단계에서 GC 프로파일링이 사라졌다. 내 반사 습관의 첫 동작이 문서에서 삭제된 것이 첫 실질 효과다.

둘째, **목표가 수정에서 재현 레시피로 옮겨갔다.** 습관대로라면 완료 기준은 "p99이 X ms 이하로 안정화"였을 것이다. 그 문장은 트래픽이 줄어도 충족된다.

## 프레임이 만든 결정적 순간

좌표계 의심 항목이 가장 컸다. 처음에는 "재집계해 본다"는 한 줄로 형식만 채울 참이었다. 부품을 실재하게 만들려면 축마다 "군집이 보일 때 어느 행이 올라가는가"를 미리 적어야 했고, 그것을 적자 원장의 순위가 뒤집혔다. 호스트 축 군집은 이웃 소음(R3)을 GC 위로 올리고, 테넌트·페이로드 십분위 축은 페이로드(R5)를 올린다. 1단계가 프로파일링이 아니라 재집계가 된 이유는 비용이 아니라 모집단이 틀릴 위험이었다.

두 번째는 승격 조건이다. "GC와 상관 있다 → 힙 플래그 투입"은 이 도메인의 기본값에 가깝다. 프레임은 상관으로는 승격 불가라고 못 박고 홀드아웃 또는 유도·제거만 인정한다. 그 때문에 3단계(아직 보지 않은 구간에 대한 사전 문장)가 생기고, 4단계는 3단계를 통과한 행만 소비하는 조건부 단계가 됐다. "3회 중 3회"도 여기서 파생됐다.

세 번째는 비용 열이다. 처음엔 "비용 오름차순으로 정렬한다"고 써놓고 표는 과제 열거 순서였다 — 선언과 본문이 어긋났다. 정렬을 바꾸는 대신 실행 단위를 바꿨다: 행 순서는 열거 순서, 실행은 A열 일괄 병렬 배치.

네 번째는 소멸 기본 행동이다. 습관적으로는 "원인 발견 후 수정"으로 끝나는 문서를 쓴다. 프레임은 "전부 기각/보류"의 출력을 미리 정하라 했고, 그래서 "판정 불가"가 정식 결론 형태로 들어갔다.

## 프레임 이탈 / 관성 회귀 지점

- **단계 번호가 상승 서사로 회귀했다.** 0→5는 읽히는 대로 사다리다. 실제 병렬은 1단계 내부(7축)뿐이고 나머지는 게이트 연결인데 형태는 계단이다. 복귀 간선 1·2·3을 명문화해 부분 보정했으나 시각적 형태는 못 고쳤다.
- **임계값을 한 문단에 몰아 "임의 선언 + 0단계 교체"로 처리했다.** 개별 근거를 붙이려 했으나 실측 분포 없이 쓰면 위조가 된다고 판단해 태그 부착에서 멈췄다. 결과적으로 원장 표의 임계값 전부가 같은 수명 하나에 매달렸다.
- **R6에서 해상도를 팔았다.** 스윕에서 나온 크론·사이드카·DNS를 원장에 착지시키려 한 행에 세 범주를 묶었다. 대칭이 깨지고 기각 조건도 뭉툭하다.
- **완화안이 관습적이다.** "요청 타임아웃 + 재시도 예산 상한"은 무난한 정답이고 프레임이 도출한 결론이 아니다.
- **분량을 한 번 눈대중으로 통과시켰다.** 1차 원고는 상한을 넘겼는데 문자 수를 세지 않고 "괜찮다"고 판정했다. 표를 남기고 산문을 깎아 맞췄다.

## 방향성

무게중심은 "무엇을 보는가"가 아니라 "무엇을 볼 자격을 얻었는가"다. 0행 게이트와 승격 조건이 데이터 접근 순서를 통제하고, 좌표 재집계가 모집단을 결정한다. 종료는 원인 발견이 아니라 재현 또는 판정 불가 선언이다.

## 자가 평가

충실도 등급: **강**. 근거는 부품이 죽인 결정이다 — 0행이 1단계에서 프로파일링을 삭제했고(§접근 및 단계), 좌표계 표가 R3·R5 승격 규칙을 만들었고, 승격 조건이 3·4단계 분리와 "3/3" 문장을 만들었고, 비용 열이 A열 병렬 배치를 만들었고, 기본 행동이 "판정 불가"를 결론으로 등재했다.

흠 셋: ① 원장 임계값 전부가 미실측이며 단일 교체 시점에 의존한다. ② R6이 세 범주를 묶어 대칭이 아니다. ③ 단계 표기가 선형이어서 복귀 간선을 읽지 않는 독자에게는 loop가 파이프라인으로 보인다. 리뷰어라면 ①을 먼저 때릴 것이고 그 순서가 맞다.
