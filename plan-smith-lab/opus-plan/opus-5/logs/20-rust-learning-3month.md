# 로그 — 20 Rust 3개월 학습 (misconception-first) [Opus 5]

## 진입 시 사고

과제를 본 직후 머릿속에 뜬 것은 주차 표였다. "1–3주 문법과 소유권, 4–6주 트레잇, 7–9주 async, 10–12주 프로젝트." 이 배치는 사실상 The Book의 목차이고, 나는 그것을 학습 계획이라고 부르는 습관이 있다. 프레임은 이 시작점을 금지한다 — 첫 실질 섹션이 목차가 아니라 **간섭 지도**여야 하므로, 주차를 쓰려면 먼저 "이 사람의 기존 지식이 어디서 배신당하는가"를 다 적어야 했다.

교정 효과는 두 곳에서 났다. 첫째, 항목의 단위가 바뀌었다. "소유권"이 아니라 "소유권을 메모리 관리 기법으로 읽는 오독"이 항목이 됐고, 그러자 무엇을 가르칠지가 아니라 무엇이 **발화하는지**를 물어야 했다. 둘째, 후보 12개 중 ORM/DI 기대치와 "에러 수 = 실력 부족" 정서를 탈락시켰다 — 후속 학습을 오염시키는 경로가 없으면 오개념 목록의 자리를 벌지 못한다(정서는 리스크로 이동). 이 탈락 기준 자체가 프레임이 준 것이다.

## 프레임이 만든 결정적 순간

순서 축을 "오염 전파"로 정하고 인접 쌍을 한 문장으로 정당화하기 시작했을 때, 결과가 교재 순서와 거의 같아졌다. 소유권 → 에러 → 추상화 → async → 공유 상태. 프레임 스펙이 명시적으로 경고하는 실패("난이도 순서가 새 축의 이름을 달고 재진입")에 정확히 착지한 것이다. 선택지는 둘이었다. 오염 서사를 더 정교하게 써서 도출로 보이게 만들기, 혹은 일치를 일치로 신고하고 축이 **실제로 갈라지는 지점**을 찾으러 가기. 후자를 택했다.

그 결과가 세 건이다. 라이프타임 애노테이션 오개념(M9)은 교재 기준 중반 주제지만, 소유 DTO만 쓰는 백엔드에게는 구조체에 참조 필드를 넣을 때까지 발화하지 않는다 — 10–11주로 내리고, 발화하지 않으면 학습하지 않는다고 썼다. `Send`/`Sync`(M7)는 "고급"으로 분류되지만 async와 동시에 발화하므로 같은 단계로 올렸다. "발화 시점 ≠ 교정 시점"을 분리한 결과 `Pin`/수동 `Future`가 봉인으로 갔다 — 호기심은 2주차에 발화하지만 그때 접촉하면 "async는 마법"으로 고착된다.

완료 기준도 바뀌었다. 처음 쓴 "clippy 경고 없이 빌드된다"는 봉인이 매체를 제거하면 자동 충족되므로, 컴파일러를 아예 배제한 판정으로 교체했다.

## 프레임 이탈 / 관성 회귀 지점

- S1→S3 세 단계는 프레임으로 도출했다고 쓸 수 없다. 정석 일치를 일치로 신고했지만, 신고가 결정을 바꾼 것은 아니다. 문서의 절반은 프레임 없이도 같았을 것이다.
- 과교정 회복을 S6(12주)에 몰아넣었다. 회귀는 교정 직후에 일어나므로 각 단계 뒤에 흩는 편이 옳았다. S2에만 부분적으로 흩고 나머지는 마지막에 쌓았다 — 상승 서사로 되돌아간 자리다.
- 뇌관 개수, 진단 임계, 적중률을 전부 임의로 태깅했다. 태깅은 준수이지 해결이 아니다. 플랜 폐기를 결정하는 40% 임계에만 중간대(40~60%)를 넣는 직접 수정을 했고 나머지는 못 했다.
- 자기 학습 충돌 공급원은 처음에 미해결로 자백만 하려 했는데, 자백 전에 수정 시도가 의무라 "매 과제마다 새 컨텍스트 + 예측 붙여넣은 뒤 진단 생성"을 넣었다. 우회가 여전히 가능하므로 등급 2로 낮춰 적었다.

## 방향성

간섭 지도를 만들면 "가르칠 목록"과 "충돌시킬 목록"이 분리되고, 후자만이 순서를 강제한다. 다음에 이 프레임을 쓸 때의 관건은 오염 전파 축이 정석과 갈라지는 지점을 **먼저** 찾는 것이다. 순서를 다 짜고 나서 찾으면 이번처럼 세 건밖에 안 나온다.

## 자가 평가

프레임 부품 **4/4 실재**, 결정을 바꾼 부품은 **3/4** — 정밀 조건 검사(0주차 진단 + 40/60 분기 → 대안 1의 부활 조건), 봉인 목록(`Pin` 봉인 → S4 이전 접촉 차단), 예측→충돌→재구성(완료 판정을 컴파일러 배제형으로 교체). 조작적 순서 축은 M9 강등·M7 승격 2건에만 작용하고 S1–S3에서는 관습과 구별되지 않는다. 흠: 회복 패스가 S6에 몰림, 공급원 등급 2, 임의 숫자 밀도, 분량 상한으로 리스크 5개(망라성 미달 가능).
