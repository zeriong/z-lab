# 전사 문서 검색(RAG) 시스템 도입
- 추론 프레임: envelope
- 한 줄 요약: 자릿수를 먼저 계산하니 문서량·임베딩 비용·갱신 주기 세 축은 아키텍처 등급을 **가르지 못했다** — 등급을 실제로 결정하는 것은 인월(10⁴ $/월)과 계산 불가능한 규제 행이며, 계산의 결과는 "관리형 조합 + 파일럿"이다.

## 1. 프레임이 요구하는 시작점 — 설계 전 자릿수 계산

내 반사는 벤더 3사 비교표부터 그리는 것이었다. 그 표는 자릿수를 모른 채 채워지므로, 여기서는 계산이 끝난 뒤에만 쓸 수 있다.

**축 A — 문서량(부피로 읽기).** 2×10⁵ 문서 × 3×10³ 토큰 = **6×10⁸ 토큰**. 청크 500토큰·중첩 20% → **약 1.2×10⁶ 청크**. 벡터 1,024차원 × 4바이트 = 4KB/청크 → 원본 **약 5GB**, 근사 색인 오버헤드 2배 가정 시 **약 10GB**. 자릿수 10¹ GB — 단일 기계의 메모리 안이다.

**축 A' — 문서량(속도로 읽기).** 신규·변경 1%/일 = 2×10³ 문서/일 = 6×10⁶ 토큰/일 = 70토큰/초. 처리량 문제가 아니다.

**축 B — 임베딩 비용(부피로 읽기).** 6×10⁸ 토큰 × 0.1 $/10⁶토큰 = **약 60~70 $**(전량 1회). 자릿수 10¹ $.

**축 B' — 임베딩 비용(속도로 읽기).** 여기서 성격이 뒤집힌다. 전량 재색인의 실제 벽은 금액이 아니라 **분당 토큰 쿼터**다. 10⁶토큰/분이면 6×10⁸ 토큰 = **10시간**. 즉 전량 재색인은 비용 사건이 아니라 **시간·쿼터 사건**이다. 월 임베딩 토큰량은 델타 기준 1.8×10⁸이고, 이 축의 자체 수행 손익분기는 **월 5×10⁹ 토큰**(= 전용 가속기 1대 상시 임대 상당액 5×10² $/월 ÷ 0.1 $/10⁶토큰, **인월 제외** 기준) — 28배가 필요하다.

**축 C — 질의량(속도로 읽기).** 1.5×10³명 × 정착 일간활성 30% × 5질의/일 = **2.3×10³ 질의/일**. 8시간 분산 시 0.08 질의/초, 피크 5~10배 → **1 질의/초 미만**. 자릿수 10⁰.

**축 C' — 질의량(부피로 읽기).** 질의당 컨텍스트 4×10³ 토큰(상위 8청크) + 출력 5×10² 토큰. 3 $/10⁶(입력)·15 $/10⁶(출력) → **약 0.02 $/질의** → 2.3×10³/일 × 22일 = **약 10³ $/월**. 생성이 전체 계산비의 98%다.

**축 D — 인월(계산에 올려야 하는 숨은 통화).** 1 인월 ≈ 8×10³ $. 색인·품질·장애 대응을 직접 지는 경로는 최소 +1 인월/월 → **10⁴ $/월**. 전체 계산비(10³)보다 **한 자릿수 크다.**

## 2. 계산이 확정한 등급

10¹ GB / 10⁰ qps / 10¹ $ 색인 / 10³ $ 월 생성비 / 10⁴ $ 인월. 상용 API와 자체 호스팅을 가르는 것은 계산비가 아니라 인월이다 — 자체 호스팅이 절약하는 최대치(10³)가 그것이 추가하는 인월(10⁴)보다 작고, 질의량이 10배 늘어도 부호는 유지된다. **따라서 등급은 "상용 API 임베딩 + 상용 API 생성 + 단일 노드 벡터 저장(기존 관계형 DB 확장)"이며, 이 판정을 뒤집을 수 있는 것은 §5의 비수치 행뿐이다.**

## 3. 문제 정의 / 목표

전사 위키·드라이브·PDF에 흩어진 문서를 자연어로 질문하고 **근거 문서를 인용한 답변**을 받는다. 목표는 두 개의 판정 가능한 상태다: ① 권한 없는 문서가 근거로 노출되지 않음 ② 월 운영비가 §1의 예측 자릿수 안에 머무름.

**이 표의 결론:** 1~4행은 10~40배(4행은 사실상 444배) 성장을 요구한다. 지시받은 네 축(문서량·임베딩 비용·질의량·갱신 주기) 중 **셋은 등급을 가르지 못한다 — 그것이 계산의 결과다.** 등급을 움직이는 것은 5·6행(선택과 인월)과 7~9행(계산 불가능한 강제 축)이다.

## 6. 재설계 트리거 (수치 선약속)

- 월 생성 청구액 > 3×10³ $ 3개월 연속 → 모델 등급 하향 + 컨텍스트 상한 재산정(청구서 기준, 플랫폼팀).
- 주 평균 일 질의 > 2×10⁴ → 서빙·등급 재판정(§5 2행).
- 청크 수 > 10⁷ → 저장 등급 재판정(§5 1행).
- 전량 재색인 1회 소요 > 24시간 → **비용이 아니라 시간이 트리거**: 쿼터 재계약 또는 재색인 단위 분할.
- **하향/철수:** 확대 후 8주 연속 주간 활성 사용자 < 전사 10%(150명) → 신규 개발 중단, 6주 관찰 후 종료 판정. 종료 시 남기는 것은 색인 파이프라인 없는 키워드 검색.
- **하향:** 답변 채택률(근거 클릭 후 60초 내 재질의 없음) < 20% 4주 연속 → 생성 경로 축소, 검색 품질 문제로 재분류. (20%는 임의선언 — M3의 첫 실측으로 교체)

## 8. 접근 및 단계 (의존 순서)

1. **규제·계약 심사** — 선행 없음(2단계와 병렬). 검증: 법무·보안의 서면 회신 1건 = 외부 전송 가능 데이터 등급 목록. 산술이 가르지 못하는 유일한 축(§5 7행)이므로 최우선.
2. **M1·M2 실측** — 선행 없음. 검증: §1 각 축의 실측 자릿수 대조표. 자릿수 불일치가 1개 이상이면 §1을 다시 계산하고 4단계를 보류한다.
3. **권한 모델 설계** — 선행 1(데이터 등급). 검증: 색인 시 문서별 ACL 메타데이터가 없으면 색인을 **거부**한다(문장이 아니라 필수 필드).
4. **단일 노드 색인 파이프라인 + 전량 색인 1회** — 선행 2(청크 자릿수 확정). 검증: 완주 시간과 쿼터 소모 기록 → §6의 24시간 트리거에 대입.
5. **검색 품질 기준선 게이트** — 선행 4. 질의 50건에 정답 문서 라벨 → 상위 10 재현율을 기존 키워드 검색과 비교. **기본값 = 중단**: 기존 검색을 넘지 못하면 생성 경로를 붙이지 않는다.
6. **생성 경로 + 인용 강제** — 선행 5 통과. 시작 등급은 §1이 계산한 중상위로 고정하고 §6의 하향 트리거에만 반응한다(상향 금지). 검증: 인용 없는 응답 비율 0, 질의당 실측 토큰 → M3.
7. **1개 부서 30일 파일럿** — 선행 6. 검증: 실측 비용·채택률·인월을 §6 트리거 표에 대입.
8. **전사 확대** — 선행 7이 하향 트리거를 밟지 않았을 때만. 게이트 기본값 = 확대 보류.

## 9. 대안과 기각 사유

- **전량 자체 호스팅(임베딩·생성·저장)** — 기각: 절약 상한 10³ < 추가 인월 10⁴. **부활 조건:** 1단계가 외부 전송 금지를 확인하거나(§5 7행), 일 질의 > 2×10⁴이면서 M4가 인월 증분 0.5 이하를 실증할 때.
- **분산 벡터 저장소 선도입** — 기각: 40배 성장 필요. **부활:** 청크 10⁷.
- **검색 없이 전 문서를 긴 컨텍스트에 투입** — 기각: 6×10⁸ 토큰/질의 = 질의당 10³ $. 자릿수로 즉사. **부활:** 입력 단가가 현재의 10⁻⁴배가 될 때.
- **RAG 없이 키워드 검색만 강화** — 기각하지 않고 5단계 게이트의 기본값으로 보유. M2에서 자연어 질문형 질의가 소수로 나오면 이쪽이 정답이다.

## 10. 리스크 & 완화

- 권한 유출 — 3단계의 색인 거부 필드로 구조적 차단(완화가 아니라 전제).
- 오래된 문서가 권위 있게 인용됨 — 근거에 최종 수정일 노출, 24개월 초과 표시(24는 임의선언).
- §1 가정 붕괴로 설계 무효 — 2단계를 4단계 앞에 고정한 것이 유일한 방어.
- 쿼터·속도 제한이 비용보다 먼저 벽이 됨 — §6의 시간 트리거.
- 채택 실패 후 좀비 시스템 — §6 철수 트리거 + 종료 시 유지 대상 명시.
- 사내 문서 자체가 틀림 — 계산 밖의 축이고 이 플랜은 해결하지 않는다(인용 표시까지가 범위).

## 11. "완료"의 판정 기준

1. **(실측 필수)** 전사 확대 후 무개입 30일의 실측 월 비용이 §1이 예측한 자릿수(10³ $/월) 안에 있다. 벗어난 경우 §5의 어느 행이 틀렸는지 지목한 대조표가 존재한다. **§6 트리거 발화로 자릿수 안으로 되돌린 기간은 적중으로 세지 않는다** — 이 문장은 프레임 자신의 출력을 반증 가능하게 만든다.
2. 권한이 다른 두 계정으로 동일 질의 100건 → 상위 10 근거 문서의 차집합이 기대 ACL과 100/100 일치.
3. 전량 재색인 1회를 24시간 내 완주한 실행 기록이 존재한다.
4. §6의 6개 트리거 전부에 담당자와 데이터 출처가 채워져 있다.
5. 철수 절차가 문서로 존재하고 한 번 예행됐다 — 판정: 색인·질의 경로를 30분 차단하고 키워드 검색만으로 동일 질의 20건이 응답된 로그.

## 12. 프레임 이탈 / 관성 회귀

- **§2의 등급 판정이 임의선언 값 하나(1 인월 = 8×10³ $)에 올라가 있다.** 실제 인건비가 3배 낮으면 인월과 계산비가 같은 자릿수가 되어 논거가 사라지는데, 검증 수단(M4)은 파일럿 이후라 그때까지 방어가 없다.
- **§5 5행(모델 등급)을 절반만 해결했다.** 6단계에서 시작 등급을 고정했을 뿐, 하위 등급으로 시작해 미달 시 올리는 반대 순서는 계산으로 비교하지 않았다 — 20~100배 레버에 대해 한 방향만 본 것은 취향이다.
- **§9의 네 번째 대안을 기각하지 않고 게이트로 넘겼다.** M2 없이는 정직하게 기각할 수 없다고 판단했지만, 판정 회피와 구별되지 않는다.
- **파일럿→전사라는 형태는 계산에서 나오지 않았다.** 자릿수는 즉시 전사 도입도 허용한다(월 10³ $, 1 qps 미만). 파일럿을 고른 실제 이유는 권한 사고의 비가역성이며 그것은 산술이 아니라 판단이다.
