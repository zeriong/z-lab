# 웹 브라우저 앵그리버드형 슬링샷 게임 — 구현 플랜

- 추론 프레임: backward(수용 기준 역연쇄) / 스타일: fable
- 한 줄 요약: 검증 가능한 4개 수용 앵커를 문서 최상단에 고정하고, 물리 엔진·렌더링·스테이지 구조·상태 머신의 모든 결정을 앵커에서 역산해 도출한다.

## 의도 패킷 (배치 테스트 — 자체 승인)

- **목표**: 브라우저 슬링샷 물리 게임 — 10개 스테이지, 코어 루프(드래그 발사→포물선→충돌·파괴→목표 제거), 우측 일시정지 버튼과 다시하기/메인으로 오버레이.
- **하드 제약**: ① 스테이지 정확히 10개 ② 물리 기반 슬링샷 플레이 성립 ③ 일시정지 버튼은 우측, 오버레이에 다시하기/메인으로 존재.
- **기각 대안**: 물리 직접 구현, 자동 러너 루프 — 근거는 본문의 kill 목록.
- **프레임 선정 근거(4술어)**: ① 불확실성 — 원인 불명 없음, 순수 실행 → Backward/Form 계열. ② 자원 경직성 — 고정 예산·기한 없음. ③ 인지 여유 — 충분. ④ 척도 합의 — 완료 기준이 요구사항에 이미 검증 가능한 형태로 존재 → **backward** 채택. api-first는 차선(최종 앱이라 "사용자 코드" 예제가 없음), emotion-curve는 기각(코어 루프가 장르 캐논으로 고정되어 감정 곡선이 설계 변수가 아님).
- **스타일 선정 근거(auto)**: 소비자가 이해관계자 아닌 구현 실행자이고, 관건이 산문 커버리지 아닌 작동 규칙(판정 함수·상태 전이·게이트) → "산출물이 운영 규칙" 신호 → **fable**.

## 프레임 진입 점검

backward의 실패 모드는 둘이다: 정해둔 결론을 향한 역산 연기, 그리고 경로 없는 앵커(판정일에만 등장하는 기준). 전자는 앵커마다 "이 기준이 죽이는 대안"을 명시해 막고, 후자는 각 단계에 서비스하는 앵커를 태깅해 막는다. 이 도메인은 캐논(Matter.js+Canvas 2D)이 지배하므로, 프레임의 가치는 정답 생산이 아니라 **캐논이 강제되지 않는 경계선 긋기**에 있다.

## 수용 기준 앵커 (프레임의 시작점)

앵커 자격 시험: "이 조건이 깨지면 최대 재작업이 발생하는가?" 통과한 4개만 앵커다.

- **A1 — 스테이지 10개, 전부 클리어 가능.** 스테이지가 데이터 파일 10개로 존재하고, 각각 클리어를 실증하는 기록이 있다. *죽이는 대안*: 스테이지별 하드코딩(포맷 수정 1건이 코드 10벌 수정이 되는 구조).
- **A2 — 물리 슬링샷 코어 루프 성립.** 드래그로 당겨 발사→중력 포물선→구조물 충돌·파괴→돼지 제거가 한 흐름으로 동작. *죽이는 대안*: 완전 강체 물리 직접 구현(회전·마찰·스택 안정성 검증이 최대 재작업 비용), 충돌 없는 궤적 연출 게임.
- **A3 — 일시정지 계약.** 인게임 우측 버튼 → 오버레이(다시하기/메인으로), 일시정지 중 물리 세계 완전 정지. *죽이는 대안*: rAF에 물리 틱을 암묵 결합한 루프(Matter.js Runner 포함) — 루프가 틱을 소유해야 하므로 수동 엔진 업데이트가 강제된다.
- **A4 — 판정의 결정성.** 마지막 발사체 소진 후 물리가 안정(settle: 모든 동적 바디의 속도가 임계 이하로 일정 시간 유지)되면 클리어/실패 오버레이가 반드시 출력된다 — 영원한 대기 상태 금지. *죽이는 대안*: 돼지 수만 세는 판정(잔여 발사체·진행 중 붕괴를 무시해 오심과 행이 발생).

자격 탈락 후보(장식 기준): "60fps 보장"(깨져도 재작업이 아니라 튜닝), "점수·별점"(가산적 — 없어도 재작업 없음). **오프-앵커 실격 선언**: 점수/별점, 사운드, 아트 퀄리티, 모바일 최적화, 스테이지 에디터는 아키텍처를 움직일 권리가 없다.

해상도 감사: 정확히 10개가 요구의 해상도다 — 낮추면 위반, 올릴 근거 없음. 측정성 편향 스윕: **"재미(난이도 곡선)"는 측정에 저항해 앵커가 없다** — 이 공백은 리스크 절로 이관하고 앵커로 위장하지 않는다.

## 앵커 교차 검토

- **A1×A2**: 스테이지 데이터는 물리 바디 서술이어야 한다(블록의 위치·크기·재질·내구도, 돼지 배치, 발사체 수). → 스테이지 = 선언적 JSON, 게임 = 그 인터프리터. 정직 기록: 데이터 주도 레벨은 게임 개발 캐논 — 레벨 시프트가 아니라 **캐논 재도달**이다. 실제 시프트는 다음 항이다.
- **A1×A4 — 레벨 시프트**: "클리어 가능"을 사람의 플레이 감상에서 **실행 가능한 검증 자산**으로 바꾼다. 각 스테이지 파일에 제작자의 솔루션 발사 시퀀스(각도·힘 목록)를 동봉하고, 고정 타임스텝 리플레이로 클리어를 기계 재현한다 — 질문("깰 수 있나?")이 프로브(리플레이 실행)가 된다.
- **A2×A3 — 의존성 발견**: 일시정지가 물리를 얼리려면 루프가 틱을 소유해야 한다 → A3가 A2의 엔진 통합 방식을 지붕처럼 규정한다. 실행 순서 도출: 상태 머신·루프 골격이 물리 통합보다 먼저다.
- **A2×A4**: 판정은 settle 신호를 소비한다 → 파괴 규칙(충격량 누적으로 내구도 차감)과 settle 임계는 같은 튜닝 축에 묶인다.

## 문제 정의 / 목표

정적 호스팅 가능한 단일 페이지 웹 게임. 기술 결정: 물리=Matter.js(수동 틱), 렌더=Canvas 2D 자체 드로잉, 스테이지=JSON 10개+인터프리터 1개, 상태 머신=메인→인게임⇄일시정지→클리어/실패. 캐논 비강제 경계: 자체 Canvas 드로잉은 앵커의 강제가 아니라 표현 자유도 확보이며, WebGL은 오프-앵커라 진입 금지다.

## 명시적 가정

- **고정 타임스텝(60Hz 수동 엔진 업데이트) 하에서 동일 입력 시퀀스는 동일 결과를 재현한다.** 검증 체계 전체가 여기 걸려 있다. 최저가 조기 검증: 2단계 직후 같은 발사를 20회 반복해 최종 바디 좌표 일치 확인. 틀렸을 때 폴백: 리플레이 검증을 "수동 플레이 클리어 기록 10건"으로 강등.
- 입력 장치는 데스크톱 마우스 기준(터치는 요구에 없음). 틀렸을 때: 포인터 이벤트 추상화로 흡수 — 아키텍처 영향 없음.
- 에셋은 자체 제작 도형/스프라이트. 틀렸을 때(원작 에셋 사용): 저작권 침해로 배포 불가(커버리지 감사에서 발견, 아래 참조).
- Matter.js의 sleeping 이벤트로 settle 감지가 가능하다. 틀렸을 때: 속도 폴링으로 대체 — 판정 모듈 1곳 교체로 국소화.

## 접근과 단계

의존성 순서다(달력 아님). 각 단계: 선행조건 / 검증 / 서비스 앵커.

1. **상태 머신 + 루프 골격** — 선행: 없음. 메인·인게임·일시정지·클리어·실패 상태와 전이 규칙, rAF 루프가 물리 틱 호출을 소유. 검증: 일시정지 상태에서 엔진 업데이트 호출 0회 로그. [A3]
2. **물리 통합** — 선행: 1. Matter.js 수동 틱(고정 dt), 지면·구조물·돼지 바디. 검증: 재현성 20회 반복 시험(가정 1의 조기 검증). [A2·A3]
3. **슬링샷 입력·발사** — 선행: 2. 드래그 벡터→발사 임펄스 변환, 발사 전 궤적 점선 프리뷰. 검증: 동일 드래그→동일 궤적. [A2]
4. **파괴·판정 규칙** — 선행: 2·3. 충격량 누적이 내구도 이상이면 파괴, 돼지 전멸=클리어, 발사체 소진+settle+돼지 잔존=실패, settle 미도달 시 타임아웃 강제 재평가. 검증: 3종 시나리오(즉시 클리어/실패/지연 붕괴 클리어) 재현. [A2·A4]
5. **스테이지 포맷·로더·월드 재구성** — 선행: 4. JSON 스키마 확정, 로드 시 월드 전체 해체·재구축. 검증: 다시하기 50회 반복 후 바디 수·리스너 수 불변 — 상태 전이 *사이*가 결정적 버그 지대다(단위 사이 수색 1회분을 여기 배정). [A1]
6. **검증 하네스(솔루션 리플레이)** — 선행: 5, 가정 1 생존. 스테이지 JSON의 솔루션 시퀀스를 자동 발사하는 개발 모드. 검증: 샘플 스테이지 리플레이가 클리어 오버레이 도달. [A1·A4]
7. **스테이지 10개 제작** — 선행: 6. 각 스테이지에 솔루션 시퀀스 동봉, 하네스로 10/10 통과. 난이도 배열은 발사체 수·구조 복잡도 기준 서수 배치(측정 척도 없음 — 임의로 선언). [A1]
8. **UI 마감** — 선행: 1(이후 병렬 가능). 우측 일시정지 버튼, 오버레이 2버튼, 클리어/실패 화면, 메인 화면. 검증: 완료 정의 2번 시퀀스 시험. [A3]

수치 태깅: 고정 dt 60Hz=캐논 도출. settle 임계와 판정 타임아웃 10초=**초기값** — 7단계 튜닝 중 스테이지별 최장 안정화 시간을 실측해 p95+여유로 교체(교체자: 구현자). 내구도·충격량 계수=초기값, 동일 트리거.

## 대안과 기각 근거

- **물리 직접 구현**: A2가 죽임(스택 안정성 재작업). 부활 조건: 번들 크기 하드 제약이 새로 등장하고 Matter.js 경량화가 불가할 때.
- **Matter.Runner 자동 루프**: A3가 죽임(틱 소유권 상실). 부활 조건: 없음 — 요구 변경 전에는 구조적 충돌.
- **WebGL/PixiJS 렌더**: 어떤 앵커도 요구하지 않는 오프-앵커. 부활 조건: 실측 프레임 드랍이 플레이를 막을 때(그때 성능이 앵커로 승격).

생존자 재귀 적용: Matter.js 채택 후 프레임을 재실행 — A3(수동 틱)·A4(sleeping 이벤트) 충족을 2단계 검증 항목으로 명시해, 생존자가 앵커를 자동 만족한다고 가정하지 않는다.

## 리스크와 완화

- **재미 공백(측정 불가 앵커)**: 완화 불가를 정직하게 인정. 7단계에서 "솔루션 외 대안 해법 1개 이상"을 제작 지침으로만 둔다(게이트 아님).
- **리플레이 비재현성**: 가정 1의 조기 검증을 2단계에 배치 — 깨지면 폴백 즉시 발동.
- **settle 미도달(미세 진동)**: 타임아웃 기본값이 흡수 — 기본값 있는 게이트만 작동하는 게이트다.
- **일시정지↔다시하기 연타로 인한 상태 오염**: 5단계의 50회 반복 시험이 전담.

## 커버리지 자기 감사

구조 몰입이 놓친 범주 스윕: **법률/IP — "앵그리버드"는 Rovio의 상표이며 원작 에셋·명칭의 사용은 침해다** → 자체 에셋 가정으로 착지시키고 명칭도 일반명을 권고. 접근성·브라우저 호환은 오프-앵커로 분류하되 기록을 남긴다. 운영 부담 감사: "리플레이 하네스의 CI 상시 자동화" 규칙을 **제거** — 1인 실행자에게 과부하이고 개발 모드 수동 실행으로 A1 검증은 충분하다.

## 어트리뷰션 노트

앵커·kill 목록·교차 검토=프레임 요구. 판정 함수·타임아웃 기본값·초기값 태깅=스타일 규율. Matter.js·Canvas 2D·데이터 주도 스테이지=도메인 캐논(재도달로 기록). 솔루션 리플레이=스타일의 프로브화 시프트.

## 완료 정의

1. **[실측]** 새 브라우저 프로필의 Chrome에서 10개 스테이지 각각의 동봉 솔루션 리플레이를 실행하면 10/10 클리어 오버레이에 도달하고 콘솔 에러 0건이다.
2. **[실측]** 임의 스테이지에서 "일시정지→다시하기→발사 1회→일시정지→메인으로→같은 스테이지 재진입"을 3회 반복해도 크래시·잔존 바디·미해제 리스너가 0건이다(개발 모드 카운터로 판독).
3. 마지막 발사체 소진 후 모든 스테이지에서 판정 오버레이가 타임아웃 이내에 표시된다 — 타임아웃 장치가 이 기준을 자동 만족시키지 않도록, 미세 진동이 남는 스테이지 1개에서 타임아웃 경로의 실제 발화를 별도 확인한다.
