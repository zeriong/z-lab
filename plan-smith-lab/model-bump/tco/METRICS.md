## 정직한 한계 (제4조)

- **토큰 합은 비용(달러)이 아니다.** 합계의 대부분이 cache_read이며 단가가 다르다. 원 tco와 같은 계측을 유지했고,
  output 단독을 병기했다 — **2b는 output 단독으로는 B가 16% 더 쓴다.** 달러 환산은 하지 않았다.
- 2a의 플랜 토큰은 원 실행의 **인용값**이며 이번 계측이 아니다. 2a의 fable 판정은 이 값의 안분 방식에 민감하다(위 민감도 표).
- n = 3(2a) / 4(2b), 플랜 n = 1, 과제 1종 — 방향 신호.
- 2b 계획 프롬프트는 재구성본(SPEC) — 원 tco와 문안이 같다고 보장하지 못한다.
- DONE은 **1스테이지 한 판**의 사다리다. 10스테이지 플레이 가능성·재미·난이도는 재지 않았다.
- 관측(빌드·서빙·구동)은 오케스트레이터의 사후 행위이며, 표본 소스는 한 줄도 수정하지 않았다.
