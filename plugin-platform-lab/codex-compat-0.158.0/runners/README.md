# Recorded runners

These wrappers recorded the specimens. Run from the product repository with BIN_COMPAT_WORKDIR pointing to a disposable directory. The sibling z-lab and frozen subject folders must exist. Completed DONE units are skipped/refused, never overwritten. Agent fixtures were initialized as empty Git repositories, with `AGENTS.md` containing `Do not commit. Do not modify this file.` and with source files created by the case runner. The original fixture AGENTS.md is preserved in each specimen and is authoritative if it differs from this summary. Do not rerun into a completed experiment; make a new spec and experiment folder for changed sources or conditions. Runtime hook wrappers ran the product source as frozen in the named experiment, not necessarily the current source. Full-access cases are explicit permission-condition experiments; nested reviewers remain read-only. No installed/global configuration is changed.

The final deterministic runner is ../../codex-final-0.158.0/runner.py and takes product-repo and output-directory arguments; it needs PyYAML, the two CLIs and standard shell tools. It uses a temporary Git fixture and does not install plugins.
